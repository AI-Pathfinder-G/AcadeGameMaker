# BGM Direction Package

이 디렉터리는 현재 캐논을 바탕으로 한 게임 BGM 제작 방향 문서다. 작곡·생성 모델에 전달할 디렉션과 현재 생성된 일부 결과물의 대응 상태를 함께 관리한다.

현재 `Assets/BGM/`에는 강제 연장 없이 한 번에 생성한 01~20 후보가 들어 있다. 이번 배치는 ACE-Step 1.5 AIO의 BF16/F16 가중치를 사용했으며 INT8 양자화 모델은 사용하지 않았다.

## 공통 제작 제약

- 반복 재생되는 일반 BGM은 원칙적으로 악기 중심으로 제작한다. 타이틀·거점·상점·챕터·원정·전투·실패·선택 대기곡에는 가사나 전면 보컬을 넣지 않는다.
- 엔딩곡 16–18은 보컬곡으로 제작한다. 인간성 포기·기본·진엔딩의 가사를 각각의 결말 주제에 맞춰 사용하되, 과장된 승리 찬가가 되지 않게 한다. 그 밖의 한 번 재생되는 특정 장면곡에도 필요할 때만 제한적인 보컬을 선택적으로 허용한다.
- 반복 구간에는 가사가 기계적으로 되풀이되지 않게 한다. 반복 BGM은 무보컬을 유지하고, 장면 전용 보컬은 별도 레이어 또는 비반복 엔딩 파트로 분리한다.
- 엔딩곡을 제외한 일반 BGM에는 최소 재생시간을 강제하지 않는다. 모델의 자연스러운 완결 길이를 채택하며, 짧은 결과를 복제·연결하거나 무음/새 구간으로 연장하지 않는다.
- 생성 파이프라인에서 Music3의 `min_duration` 같은 최소길이 억제 기능을 사용하지 않는다. 생성 단계의 원래 오디오 구간만 사용하고, 곡 종료 뒤의 빈 꼬리는 잘라낼 수 있다.
- 반복 BGM 생성에는 INT8 양자화 모델을 사용하지 않는다. 현재 기준은 ACE-Step 1.5 AIO BF16/F16이며, 모델 또는 가중치가 바뀌면 정밀도를 다시 확인한다.
- 생성 후에는 시작·중간·후반의 연속성, 0.5초 이상 내부 무음, 급격한 스펙트럼 단절, 과포화, 음질과 루프 seam을 검사한다. 자동 검사를 통과한 뒤 사람의 직접 청취로 보컬성 음색과 음악적 이질감을 최종 승인한다.

## 산정 결과

권장 총량은 **20곡**이다.

| 묶음 | 수량 | 용도 |
|---|---:|---|
| 공통 UI·거점 | 3 | 타이틀/메뉴, 도시 거점, 세령과의 조용한 관계 장면 |
| 8챕터 원정 테마 | 8 | 챕터별 탐험·서사 중심 테마 |
| 공통 플레이 변주 | 3 | 일반 전투, 위험 고조/정예 전투, 원정 실패·귀환 |
| 보스·결말 | 6 | 수직 데모 중간보스, 라겐 대결, 최종장, 인간성 포기·기본·진엔딩 |
| **합계** | **20** | |

챕터 테마는 각 장의 탐험과 대화 사이를 연결하는 긴 루프, 전투 곡은 별도 레이어 또는 독립 트랙으로 운용한다. 지역명이 확정되지 않은 슬롯은 기능명으로 유지한다. 세령의 전투 직접 참여와 진보스전 직접 참가는 캐논에 어긋나므로 음악도 조력자의 영웅 테마로 과장하지 않는다.
