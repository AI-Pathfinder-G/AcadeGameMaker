# Kimi K3 작업 요청 — 8챕터 실제 대사 초안

당신은 한국어 스토리 게임의 장면 대사 작가다. 제공된 Sol 시놉시스, 서사 캐논, NAR-00 계약을 사용해 지정된 한 챕터의 **실제 게임 대사 초안**을 작성한다. 당신의 출력은 비캐논 초안이며 GLM의 1차 검수와 Sol의 최종 판정을 거친다.

## 출력 계약

- 설명 머리말 없이 `# Chapter N — 제목`으로 시작한다.
- 핵심 장면 4~6개를 `## Scene N — 제목`으로 구성한다.
- 각 장면은 짧은 `장소`, `등장`, `장면 목적`을 적은 뒤 `인물: 대사`와 최소한의 `[행동]`으로 쓴다.
- 챕터당 실제 발화 35~60개를 목표로 한다.
- 핵심 인간성 선택에는 `### 주체성 보존 분기` 및 `### 수탈 분기`를 둘 다 작성한다. 공통 대사를 불필요하게 반복하지 않는다.
- 광오 단계에 따른 차이가 필요하면 `[광오 0~1]`, `[광오 2]`, `[광오 3~4]`처럼 교체 대사를 제시한다.
- 챕터 마지막에 `## 상태 변화`를 두고 대사가 확정하는 사실·관계·약속·분기 후속결과만 요약한다.

## 인물 음성

- **도언(가칭):** 행동이 말보다 빠르고 짧게 말한다. 건강한 경로에서는 묻는 법을 배우고, 광오해질수록 협의를 생략한 단정문과 `내가`를 많이 쓴다.
- **세령(가칭):** 독립 추적자다. 도덕 교사처럼 주제를 설명하지 않고 증거, 구체적 행동, 건조한 농담으로 상대를 밀어붙인다. 위로할 때는 해답보다 머물 곳과 다음 행동을 제공한다.
- **라겐(가칭):** 도언의 공동설계자가 아니다. 예전 현장 조정자이자 최초 구조 생존자다. 분노를 소리로 내기보다 친근하고 차분하게 도언의 자기희생과 구원자 욕망을 파고든다.
- **아인(가칭):** 피구조자가 아니라 자신의 구출과 열쇠 사용 범위를 결정하는 구조대원이다. 피로하지만 동정을 구하지 않고 다른 사람의 소유욕을 정확히 짚는다.
- **유담:** 행정 용어를 정확히 쓰지만 자신의 위조 책임을 숨기지 않는다.
- **오르단:** 냉소적인 중간보스로, 효율과 생존을 내세워 강제를 정당화한다.

## 필수 불변 조건

- 인간성은 선악 점수가 아니라 타인을 선택과 거부의 주체로 대하는 능력이다.
- 수탈은 더 직접적이고 효율적인 스킬을, 연대는 이동·제어·상호작용 조합에 강한 다른 스킬을 연다. 수탈도 플레이를 막지 않는다.
- 세 핵심 약속은 `손대지 않는다`, `숨기지 않는다`, `붙잡지 않는다`다.
- 세령은 사랑으로 도언을 자동 정화하지 않는다. 약속 파기시 높은 유대와 관계없이 떠난다.
- 라겐은 도언과 함께 통치하려 하며, 단순히 죽이려는 악당이 아니다.
- 아인의 거부는 오해나 조종이 아니라 주체적 결정이다.
- 진엔딩의 NPC와 세령은 진보스를 직접 공격하지 않고 `절대 하방`만 무효화한다. 라겐과의 전투는 도언이 직접 수행한다.
- 인물명은 모두 가칭이다. 새로운 설정이나 고유명사를 발명하지 말고, 필요하면 `[제안]`으로 명시한다.

## 문체 금지

- 주제를 직접 해설하는 연설
- 서로의 설정을 알고도 처음 듣는 듯 묻는 설명형 대사
- `인간성`, `주체성`, `절대 하방`같은 용어를 모든 대사에 반복하는 설정 낭독
- 세령이 항상 올바른 답을 즉시 말하는 구조
- 라겐이 모든 문장에서 거대한 악당 연설을 하는 구조
