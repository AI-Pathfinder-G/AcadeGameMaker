# GLM 5.2 Cloud Finalist B — Non-canonical

다음 고정 캐논을 지키며 최종 후보 B만 한국어 1800단어 이내로 완결하라.

- 인간 대리추 주인공은 처음부터 동의 기반 공명의 최초 설계자다. 권력층이 동의 절차를 제거했고 그는 시스템을 없애려다 기억·원형을 여러 사람의 각인에 분산했다.
- 유담은 47인의 동의 서명 보관자이나 위조 책임이 있고, 오르단은 질서를 위해 장부를 압류하는 인간 환수관이다.
- 히로인은 조건 있는 인간의 닻이자 후속 일반 원정의 자율 지원 사이드킥이며 최종보스에는 직접 참전하지 않는다.
- 중심 미스터리: 권력층이 분산된 원형 설계 조각을 이용해 죽거나 떠난 사람의 `중력 서명`을 위조하고 부채 계약을 자동 갱신한다. 서명은 동의의 증거일 뿐 동의 자체가 아니다.
- 8챕터 모두 서로 다른 인간 갈등·인간 보스. 선택은 공개 범위, 책임 인수, 약속, 위험 분담, 거부 수용, 제한 협력, 복구 우선순위 등으로 다양화한다.
- 진보스는 추상적 권력 대표·오해한 조수·효율 광신자가 아니어야 한다.
- 인간성 포기 시 히로인이 떠나며, 인간성 보존+NPC 자발적 공명으로 `각자의 아래`가 절대권능을 무력화한다. 높은 유대는 진엔딩 필요조건이지만 인간성을 대체하지 않는다.

출력:
1. 제목·훅·중심 질문
2. 이름이 있는 주요 인물 8명(주인공·히로인·유담·오르단 포함)의 성격·욕망·결함·관계·픽셀 실루엣/주색/소품
3. 8챕터 각각 지역, 중심 갈등, 인간 보스, 플레이 사건, 폭로, 고유 선택과 양쪽 손실, 히로인/사이드킥 변화, 과거 단서
4. 세 엔딩 차이
5. 진부함·설정 붕괴 위험 5개와 보정
