# GLM 5.2 Cloud Revision Prompt — Non-canonical

앞선 버전 1 `하중의 서약`과 버전 2 `낙하세표`는 Sol 검토에서 상세화 대상에서 제외됐다.

## 반려 코멘트

- 주인공을 원래 수탈적 부채 전이 시스템의 설계자·낙하장 공동 설계자로 바꾸면 안 된다. 고정 캐논은 주인공이 처음부터 `동의 기반 중력 공명`의 최초 설계자였고 권력층이 동의 절차를 제거해 변질시켰다는 것이다. 주인공의 죄와 결함은 이 사실을 뒤집지 않는 다른 방식으로 설계하라.
- 도시 중력 전체를 무한 추락 인간 발전소 하나로 환원하지 말라. 중력 배급망·하방권·부채·대리추의 사회 구조를 보존하라.
- 미성년자가 다른 사람을 위해 영구 고통에 남는 선택을 감동으로 소비하지 말라.
- 각 챕터 선택을 매번 `강제 추출 vs 존중`의 동일한 버튼으로 반복하지 말라. 책임 인정, 진실 공개 범위, 약속 이행, 불완전한 연대, 생존권 충돌 등 서로 다른 인간적 딜레마를 사용하라.
- 이름·설정 불일치와 환경/자동 시스템 중심 보스를 피하라. 각 챕터의 핵심 상대와 보스는 동기·책임·타협 불가능한 지점을 가진 인간이어야 한다.
- 게임 안에서 `수직 데모`라는 개발 용어를 사건 이름으로 쓰지 말라.

## 고정 캐논 재확인

- 인간 대리추 주인공, 동의 기반 공명의 최초 설계자, 기억과 원형 설계를 여러 사람의 각인에 분산.
- 유담은 47인의 동의 서명 보관자이지만 위조로 타인을 위험에 빠뜨린 책임이 있다.
- 오르단은 질서를 지키려 공동장부를 압류하는 인간 환수관이다.
- 히로인은 독립된 추적자이자 조건 있는 인간의 닻. 수직 데모 마지막 첫 등장 뒤 후속 챕터에서 자율 지원 사이드킥이 된다. 최종보스에는 직접 참전하지 않는다.
- 8챕터 모두 다른 인간과의 충돌이 중심이다.
- 수탈·연대는 모두 진행 가능하고 단순 선악이 아니다.
- 인간성을 버린 최종 선택에서는 히로인이 떠난다. 인간성 보존+NPC 자발적 공명으로 `각자의 아래`가 진보스 절대권능을 무력화한다.
- 유대도 높은 진엔딩은 검토 대상이지만 인간성 조건을 대체하지 않는다.

## 새 요청

앞선 두 안과 핵심 미스터리·정치 구조·관계 비극이 다른 새 버전 3개를 작성하라. 각 버전은 다음을 포함한다.

1. 제목·한 문장 훅
2. 주인공·히로인 이름 제안과 유담·오르단 포함 주요 인물 6~9명의 성격·욕망·결함·실루엣·색·소품
3. 8챕터별 지역, 인간 갈등, 상대 인물, 플레이 사건, 폭로, 서로 다른 종류의 선택/결과, 히로인 관계 변화, 인간 보스
4. 수탈 누적·인간성 보존·높은 유대 진엔딩 차이
5. 주인공 과거·능력의 단계적 폭로
6. 자체 진부함/설정붕괴 위험 3개와 보정법

각 버전은 1400~1800 한국어 단어 내외로 압축하고 이름만 바꾼 동일 플롯을 금지한다.
