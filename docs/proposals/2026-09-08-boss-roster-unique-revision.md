# 보스 반복 제한 반영 — 8개체와 새 5장 보스 채륜

- 상태: **Draft / 사용자 검토용**, 2026-09-08. 설계·통합 Astra.
- 확정 지시: 동일 캐릭터의 보스 반복은 최대 1개체. 나머지는 다른 캐릭터로 구성한다.
- 본안 선택: 라겐의 최종 장치전→진보스전만 반복, 오르단 재대결 철회. 인간 보스 6명·생물 보스 2개체, 총 8개체/9개 전투 형태다.
- 채륜의 이름·성별·과거·패턴·5장 연결은 새 제안이며 캐논 등록/구현 승인은 아니다. 이미지 생성·다른 방에 발주·런타임 변경은 하지 않는다.
- 이 문서는 [최초 보스 패키지](./2026-09-08-chapter-boss-design.md)의 배정표와 B05·관련 시안 지시를 대체한다. 다른 보스의 상세 초안과 공통 안전/분기 원칙은 유지한다.

## 1. 수정된 배정

> 2026-09-09 후속 지시: 사용자가 서하의 보스전→비밀상점 NPC 서사를 지정했다. [ADR-0029](../adr/0029-seoha-rivalry-and-secret-shop.md)에 따라 서하전을 다시 포함하며, 아래 8개체 표의 6장 배정과 총수는 재조정 대상이다. [서하 후속안](./2026-09-09-seoha-romance-secret-shop.md)의 배치안을 함께 검토한다. 기존 생물 시안은 보존하며 동일 보스 반복 상한은 유지한다.

## 2. 석방 중개인 채륜 — 사람의 자유를 파는 사람

### 외형과 성격

한때의 수감복 위에 잘 재단한 짧은 외투를 걸친 여성. 목의 옛 수감 표식은 가리지 않는다. 접이식 열쇠판 세 장과 길이가 다른 수동 발사기 두 개를 쓰며, 큰 외골격 대신 날렵한 옆걸음과 회전판이 실루엣을 만든다. 열쇠판은 이동 엄폐 겸 지정된 탄의 기계식 반사 장비다.

협상할 때는 상냥하고 상대의 사소한 취향까지 기억하지만, 거래를 거부하면 비용을 따지는 말투로 바뀐다. 과거 다른 수감자들의 탈출 계획을 팔아 자기 자유를 샀고, 이제는 억류시설의 석방 심사·보증 거래를 위탁받아 돈을 번다는 설정을 제안한다. 제도가 부당하다는 것을 알면서 이용한다. 불가피한 선행을 내세우는 보스들과 달리 야심과 착취의 책임을 가진 인물이다.

**오르단과의 차이:** 오르단은 질서를 지켜야 한다고 믿지만 채륜은 질서가 망가질수록 돈을 번다. 그녀에게 도언은 재앙이나 구원자가 아니라 비싸게 팔 수 있는 이름이다.

### 기존 5장에 들어가는 흐름

1. **3~4장 예고:** 석방 보증표·미뤄진 석방 기록으로 이름을 먼저 알린다. 신문/증언 같은 현재의 흔적이며 도언의 숨겨진 옛 동료로 만들지 않는다.
2. **5장 체포:** 오르단의 체포 역할은 비전투 서사로 보존한다. 승리 불가능한 오르단 보스전을 끼워 넣지 않는다. 세령의 동행 여부에 따라 동시 체포 장면은 분기한다.
3. **거래 제안:** 채륜은 도언에게 출구와 좋은 대우를 제시하고, 대신 그의 이름으로 수감자들의 새 보증 계약을 공개 승인하라고 요구한다. 도언의 명성이 계약을 믿게 하는 담보가 된다.
4. **조건 폭로:** 문서에는 사람들의 각인 사용 범위와 이탈권을 묶는 조항이 있다. 각인을 흡수하는 능력이 채륜에게 있는 것은 아니다. 시설 권한과 계약 집행을 악용하는 사람이다.
5. **충돌:** 도언이 수감자와 탈출하거나 시설을 힘으로 접수하려 하면 채륜은 독점권을 지키기 위해 무장한다. 연대 경로에서는 각자의 협조로 빠져나가고, 수탈 경로에서는 중개인을 밀어낸 도언 자신이 타인의 힘을 점유하려는 모습을 보인다.
6. **전투 이후:** 봉쇄 장비가 멈춰 수감자와 직접 대화할 수 있게 된다. 격파는 각인 사용 동의가 아니다. 시민이 도언을 어떻게 보는지는 실제 선택 이력에 따라 달라진다.

이렇게 5장의 과거 폭로·구금·탈출·구원자 이미지·자기정당화라는 줄기를 유지하면서 전투 상대를 교체한다. 채륜을 자동 설계 열쇠 보유자나 신규 스킬 지급자로 만들지 않는다.

## 3. 전장과 공격 패턴

석방 접수홀에서 공개 이송 마당으로 이어지는 두 교전 구역. 각 구역의 공격 원점·예고·안전 위치가 고정 배율 화면 안에 보여야 한다. 수감자 대기실은 전투 경계 밖이며 열쇠판은 감방 문이 아니다. 판을 공격한다고 사람이 피해를 입지 않는다.

| 공격 | 준비 → 실행 | 대응·빈틈 |
|---|---|---|
| **열쇠판 전개** | 회전축 소리와 다음 위치 표시 → 엄폐판을 순서대로 이동 | 열린 동선으로 자리 확보. 이동 중 사격을 겹치지 않고 정착 뒤 다음 예고 시작 |
| **교차 견적** | 두 발사기를 다른 높이로 겨눈 뒤 방향 고정 → 직선탄 두 발을 시차 발사 | 엄폐 또는 두 궤적 밖 이동. E2의 Y 무관 판정선이 아닌 유한 투사체. 재장전 중 반격 |
| **반송탄** | 지정 반사판을 펼치고 입사·출사 궤적을 함께 표시 → 한 번만 반사하는 큰 탄 | 반사판 기준 안전측 이동. 연속 도탄·유도·지형 관통 없이 종료. 발사 뒤 긴 수동 장전 |

**1단계:** 판 하나와 탄 하나의 독립 순환으로 시작해 반사 궤적부터 배운다. 넓은 안전측을 남기고 다른 공격을 동시에 넣지 않는다. 이후 세 판을 번갈아 이용하는 엄폐·사격전으로 발전한다.

**2단계:** 손상된 판을 접어 엄폐가 줄어드는 대신 직접 자리를 바꾸며 교차 견적과 반송탄을 순차로 연결한다. 이동에 무적·순간이동을 주지 않고 사격 전에는 반드시 멈춰 조준을 고정한다. 기본 공격과 정상 이동으로 끝낼 수 있는 장전 창을 유지한다.

반송탄은 보스의 신규 문법이다. 일반 적 E2/E4를 배웠다는 이유로 반사까지 안다고 가정하지 않는다. 5장 앞부분의 E4/E6 신규 학습과 거리를 두고 안전 구간을 거쳐 보스전에 진입한다. 도탄 각도·탄속·경고시간·실패 비용은 후속 계약/플레이 검증 사항이다.

### 무게 전이와의 관계

- 본체 대신 **전개 준비 중인 열쇠판 하부 균형추 하나**를 대상으로 하는 안이다. Heavy로 이동/전개를 중단해 엄폐를 줄이고 수동 복구 창을 만든다.
- 발사 전에 반사판이 과하중이면 해당 반사 공격을 취소한다. **탄이 발사된 뒤에는 그 탄이 쓰는 판의 변형과 새 전이를 잠가**, 이미 읽은 출사 궤적을 뒤집지 않는다. 잠금 여부는 조준 피드백으로 보여줘야 한다.
- 기존 탄의 수명과 충돌은 별도 소유이며 사망/Heavy가 이미 발사된 탄을 소급 취소하지 않는다. 카메라 경계·지형 충돌·피해 중복 제거를 선행 계약한다.
- 전이 1대상·6u/LOS·21틱 잠금, 비무적 대시를 보존한다. 장비 반응은 신규 보스 계약이며 일반 적 Heavy의 공격 강화로 처리하지 않는다. 전이 없이도 재장전 창에 기본 공격으로 승리할 수 있다.

## 4. 선택·연속성에서 고칠 부분

- 기존 시놉시스의 5장 오르단 각인 수탈을 **채륜의 새 각인 보상으로 단순 치환하지 않는다**. 정확한 수탈 대상·오르단의 현장 잔류 여부는 OD-NAR-003에서 다시 정한다. 새 보스 선택과 인간성 선택의 대상은 별개다.
- 유담의 장부 능력을 잃은 경로는 탈출 때 능력이 복구되지 않는다. 세령 미동행 경로도 거래 정보·도움의 대체 제공자를 별도로 둔다. 새 보스 승리로 약속 위반이나 진엔딩 부적격을 지우지 않는다.
- 오르단의 후속 대화는 유지 가능하지만 전투를 다시 요구하지 않는다. 5장 상태에 따른 7장 공명 능력도 자동 복구하지 않는다.
- 채륜의 생존·구금·도주 중 정확한 종료 상태는 후속 서사 승인 대상이다. 도주하더라도 후반의 두 번째 보스전으로 복귀시키지 않는다. 새 진엔딩 필수 공명 인물로 추가하지 않는다.

## 5. 다른 방의 시안 제작용 지시

**B05 오르단 재대결 시안은 취소하고 채륜을 신규 제작한다.** 실제 다른 작업에 명령을 전송한 것이 아니라 이 문서의 제작 기준이다.

- 짧은 외투, 남겨 둔 수감 표식, 세 접이식 열쇠판, 길이 다른 발사기. 오르단의 얼굴·외골격·압류추·집행봉을 공유하지 않는다.
- 협상 자세 / 판 이동 준비 / 두 높이 조준 / 반사판 전개 / 수동 재장전 / 판을 접은 2단계 자세를 분리한다.
- 마법 거울 대신 각도가 읽히는 기계식 반사판. 사람을 판에 매달거나 인간 각인을 탄약으로 그리지 않는다.
- [미술 캐논](../canon/art-direction.md)의 팔레트와 의미색 구분을 따른다. 외형 그림은 구현 수치나 새 전이 규칙의 승인이 아니다.

## 6. 검토 상태와 추적

보스 반복 상한과 8개체 구성은 사용자 지시를 반영한 배정이다. 채륜 상세는 Draft로 남긴다. 기존 B01과 B08/BT 동작 경계는 그대로다. 새 전투는 준비/실행/회복 기한·피해/경직·판/탄 수명·전이 잠금·단계 전환·재도전 계약이 필요하다.

추적 근거: BOSS-F의 공간/예고/기술 보존 제약, VD-02 REQ-WT-006~008 / AC-WT-003~005, VD-01 REQ-MOV-008 / AC-MOV-005, NAR-00 Review OD-NAR-003. 이번 문서는 런타임 또는 인수 테스트 통과 증거가 아니다.

독립 문서 검토: Luna가 최신 수정안과 원 패키지의 표/첫머리/B05 철회/시안 지시를 대조해 P0=0, P1=0, P2=0으로 보고했다. 반복 제한의 REQ-BOSSF-012 / AC-BOSSF-008 문서 검토에서 8개체·9형태·라겐만 반복·오르단 후속 비전투 역할이 일치함을 확인했다. 채륜의 전이/반사판 잠금/조준 피드백과 혼합 서사 상태 보존도 대조했다. 이는 실제 공격·피해·반사 궤적의 플레이 검증이 아니다. 새 인물과 전투 수치는 여전히 Draft다.
