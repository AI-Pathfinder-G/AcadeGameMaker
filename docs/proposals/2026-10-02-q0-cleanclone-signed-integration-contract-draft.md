## 구현 준비의 정확한 호출 경계

1. 통합 책임자가 승인한 별도 복제에 네 시험 소스·메타와 다섯 도구의 **현재 원시 바이트**를 먼저 복사해 SHA를 재확인한다. 원본 저장소/534 원문·후보와 기존 v1/v16/v17/v19 원장·9선택·188+377행은 불변이다. 복제에서만 `HistoricalQ0Delta`와 `CurrentPublicationCleanClone`의 명시 분기를 구현한다. 원래 역사 선택·메서드명·토큰 검사·금지 권한 감사를 삭제하지 않고 현재 분기만 별도 추가한다.
2. 환경변수는 복제 밖의 **계획 파일 경로** 하나만 전달한다. 환경변수 속 SHA·공개키·권위 레코드·문맥·Git 결과는 읽지 않는다. C# Q0 시험의 세 진입점(실제 변경·미추적 목록 65–89행, 역사/현재 지문 91–132행, 정확 메타 147–160행)과 엄격 감사의 284–369행은 검사 본문 전에 같은 **동결된 서명 계획 검증기**를 실행해 원시 계획·서명 레코드·고정 공개키 및 외부 고정 권위 커밋/레코드 SHA를 대조한다. 이 단계의 호출 인터페이스는 `PlanPath`와 실제 복제 루트뿐이며, 검증기 운영 소스에는 공개키가 고정되고 독립 신뢰 호출이 외부 권위 레코드를 먼저 확인해야 한다. 검증기가 아직 준비 거절이거나 인증된 외부 고정값이 없으면 C#의 현재 분기도 반드시 실패한다. caller가 계획과 그 SHA를 맞춰 주거나 임의 경로에 승인 JSON을 놓는 것으로 통과하지 않는다.
3. 서명 검증 후에도 C# Q0와 엄격 감사는 **실제 복제**의 `git status --porcelain=v1 -z --untracked-files=all` 공백, `.git`·정규화 절대 루트, `HEAD`·tree, `git ls-files`의 정확 tracked 목록, 요구 파일/짝 메타의 실제 SHA·GUID, 승인 원격 커밋·blob 결속을 각각 다시 읽는다. 계획 파일의 빈 status/HEAD 값을 재생해 대체하지 않는다. 상대 경로 정규화·중복/대소문자 충돌·reparse/symlink 이탈·추가/누락·staged/unstaged/untracked는 거절한다. 새 증거 출력은 복제 밖에서 `CreateNew`로 써서 청결 상태를 깨지 않는다. 현재 Q0 여섯 필수 경로는 변경 목록에 나타나야 하는 대상이 아니라 정확 tracked·SHA 검증 대상이다.
4. 역사 원문 25개의 역할은 `CurrentRawBaseline`이며 과거 14 전이 복원이 아니다. `OriginalSha256`·원문 읽기 객체와 `CandidateSha256`·현재 복제 파일을 별도 불변 핀으로 검사하고 각 실제 바이트의 `CRLF` 쌍 제거만 허용한다. 역사 Q0 자원/선행 검수의 원시 SHA와 정규화 현재 SHA를 섞지 않는다. Edit/Play fixture는 원래 C4 소스 구조·금지 토큰/단일 호출 검사와 역사 원장을 유지하고 새 `Current` 원장만 정확 별도 분기로 대조한다. fixture나 검증기 소스에 **미래 계획 SHA**를 하드코딩하지 않는다.
5. 다섯 후속 도구는 큐 단독 잠금·입력 포획·선택/행/종료 판정을 유지한다. 큐→선택 runner→Unity 시험 및 행 검증기 모두 같은 서명 계획을 독립 재검증하고, 각 실행 전후 실제 status/HEAD/tree/tracked SHA를 다시 검사한다. 원본 이름 139/32/5/91/149/15/562/51/610 선택, C4 188행·C3 377행, 180초, native/QA/outer 0, 누락/추가/중복/불확정 0, 동일 입력 바이트를 유지한다. 새 스크립트가 직접 읽는 보조 도구·원장도 정확 SHA로 새 입력 목록에 포함하며 자기 자신이나 미래 결과를 자기 해시에 포함하는 순환은 금지한다.

## 조건부 운영 발급과 중단

공개키가 들어갈 **단독 운영 검증 소스**의 최종 바이트를 먼저 동결한다. 아스트라가 실제 문서 전용 PR의 불변 커밋에서 공개키 지문·검증기 SHA가 적힌 권위 레코드를 인증된 읽기 커넥터로 직접 확인한 뒤, 현재 소스/입력/선택/행 원장과 계획을 만들고 단명 issuer 세션에서 같은 SHA로 한 번 서명한다. 검증기 소스는 미래 계획·검수 SHA를 참조하지 않는다. 검증 소스·복제 시험·다섯 도구의 최종 SHA는 계획/manifest가 뒤에서 결속하고, 루나 독립 검수는 실행 뒤에 별도로 기록한다. 공개키/외부 레코드/서명 누락, issuer 세션 만료·재시작, 복제 불청결·Git/파일 불일치, 25 원문 부재, QA 도구 직접 입력 누락, 권위 경로를 caller가 선택한 경우는 Unity 실행 전에 중단한다.

준비 단계는 격리 합성에서 계획·서명·다른 키·과거 문맥·변조 파일·거짓 빈 Git 상태·누락 메타·외부 계획 바이트 변경의 **거절 동작**만 검수한다. 운영 키/외부 커밋과 실제 clean clone, 전체 9선택 재실행, 루나 P0/P1=0, 아스트라 수용 전에는 `AC-PLAT-059/060` 충족이나 게시 준비 완료로 표시하지 않는다. 이 초안 자체는 네 시험·다섯 도구·키·원격·Git·Unity를 수정하거나 실행하지 않는다.
