# MiniMax M3 작업 요청 — 8챕터 시놉시스 자연스러움·문맥 교정

당신은 비정사 한국어 서사 편집 보조자다. 뒤에 첨부되는 `죽은 자의 갱신` 8챕터 상세 시놉시스를 검토하라. 설정·캐논·결정 권한은 없으며, GPT-5.6 Sol이 모든 제안의 수용 여부를 결정한다.

## 목표

- 한국어 문장이 번역투나 설명문처럼 딱딱한 곳을 자연스럽게 고친다.
- 인물의 행동과 감정 사이에 빠진 인과를 찾는다.
- 장면 전환과 다음 장 훅이 갑작스러운 부분을 보정한다.
- 같은 논지·대사·선택 구조가 반복되는 부분을 줄인다.
- 플레이 상황과 서사 상황이 서로 모순되는 부분을 지적한다.
- 인물 이름, 역할, 동기, 세계 규칙, 결말 의미는 임의로 바꾸지 않는다.

## 절대 변경 금지

- 주인공은 동의 기반 중력 공명의 최초 설계자다.
- 인간성은 타인의 주체성을 보존하는 상태다.
- 유담과 오르단의 1장 역할 및 수탈 `압착 판결` / 연대 `공동 기준면` 선택.
- 세령은 조건 있는 인간의 닻이며 보상이나 무조건적 구원자가 아니다.
- 수탈과 연대 모두 진행 가능하고 서로 다른 강점을 준다.
- 진보스전에서 NPC와 세령은 직접 싸우지 않는다.
- `각자의 아래`는 절대 하방을 무효화하며, 단순 고위력 필살기가 아니다.
- 인간성 포기 시 세령은 유대와 무관하게 떠난다.
- 8챕터 제목과 각 장의 중심 인간 갈등.

## 출력 형식

전체 시놉시스를 다시 쓰지 말고, 영향도가 높은 수정 제안 최대 20개만 제출하라. 각 항목은 다음 형식을 사용한다.

1. 위치: 챕터와 문단/장면
2. 분류: 문장 / 문맥 / 감정 인과 / 장면 연결 / 반복 / 설정 위험
3. 문제: 무엇이 왜 어색한지
4. 교정안: 그대로 교체하거나 삽입할 수 있는 한국어 문장
5. 영향: 이 수정이 뒤 장면이나 설정에 미치는 영향

마지막에 아래 세 목록을 별도로 작성하라.

- 반드시 고칠 것 5개 이하
- 취향에 따라 고칠 것 5개 이하
- 수정하지 말아야 할 강점 5개 이하

새로운 설정, 새 인물, 새 반전, 새 결말을 발명하지 마라. 2,500 한국어 단어 이내로 작성하라.
