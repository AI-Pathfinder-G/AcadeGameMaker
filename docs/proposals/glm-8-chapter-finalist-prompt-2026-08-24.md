# GLM 5.2 Cloud Finalist Revision Prompt — Non-canonical

Sol의 2차 판정:

- `침묵의 도면` 반려: 주인공이 동의 절차를 직접 지웠다는 훅은 권력층이 동의를 제거했다는 캐논과 충돌한다. 히로인의 신뢰가 무조건 신뢰로 변하는 것도 금지한다.
- `제7계층의 약속` 조건부: 주기적 부채 초기화는 신선하지만 만능 리셋이면 세계 경제가 붕괴한다. 이를 `동의와 부담 위탁은 일정 기간 뒤 만료되고 당사자가 갱신해야 한다`는 원형 설계의 안전장치로 바꾸면 유효하다.
- `빚의 주파수` 조건부: 위조 갱신 서명 미스터리는 강하지만 동의를 기계가 판별하는 음파로 축소하면 안 된다. 중력 서명은 동의의 증거일 뿐 동의 자체가 아니며, 사람의 의사를 별도로 확인해야 한다. 측정 장면 반복과 오해한 조수 최종보스는 피한다.

## 최종 요청

서로 다른 최종 후보 2개를 작성하라.

### 후보 A — 만료된 약속

원형 공명에서 부담 위탁은 영구 소유권 이전이 아니라 일정 기간 뒤 만료되는 계약이었다. 권력층이 `만료·재동의` 절차를 제거해 한 번의 서명을 영구 부채로 만들었다. 이 구조를 중심으로 8챕터를 설계하라.

### 후보 B — 죽은 사람의 갱신

권력층이 주인공이 분산한 원형 설계 조각을 이용해 죽거나 떠난 사람의 중력 서명을 위조하고 부채 계약을 자동 갱신한다. 서명은 증거일 뿐 동의 그 자체가 아니며, 각 챕터는 실제 사람의 의사와 기록 사이 충돌을 중심으로 설계하라.

## 공통 필수 조건

- 주인공은 처음부터 동의 기반 공명의 최초 설계자다. 권력층이 동의 절차를 제거했고 주인공은 시스템을 없애려다 기억·원형을 사람들의 각인에 분산했다.
- 주인공에게 실질적 책임과 결함은 주되 원래 수탈 설계자로 바꾸지 말라. 예: 제도가 인간의 악용을 버틸 것이라 과신, 각인 보유자에게 충분히 설명하지 않고 기억을 맡김, 혼자 제거하려다 사람들을 위험에 빠뜨림.
- 유담·오르단의 기존 캐논을 유지한다.
- 히로인은 조건 있는 인간의 닻이며 절대 무조건 신뢰로 변하지 않는다. 일반 원정 자율 지원은 가능하지만 최종보스에 직접 참전하지 않는다.
- 8개 챕터 모두 동기·책임·타협 불가능한 지점을 가진 다른 인간이 중심 상대·보스다.
- 챕터 선택의 종류를 다양화하라. 공개 범위, 책임 인수, 약속 이행, 위험 분담, 거부 수용, 제한된 협력, 복구 우선순위 등이 서로 반복되지 않게 하라.
- 진보스는 추상적 권력층 대표, 오해한 조수, 단순 효율 광신자가 아니어야 한다. 주인공과 다른 정당성·구체적 손실·되돌릴 수 없는 책임을 가진 인간이어야 한다.
- 최종 선택·각자의 아래·유대 조건은 기존 캐논을 따른다.

각 후보마다:

1. 제목·훅·중심 질문
2. 주인공·히로인 이름 제안과 유담·오르단 포함 7~9명 캐릭터: 성격, 욕망, 결함, 관계, 640×360 픽셀 실루엣·주색·소품
3. 8챕터: 지역, 중심 인간 갈등, 상대/보스, 플레이 사건, 폭로, 고유 선택과 양쪽 실제 손실, 히로인 관계/사이드킥 발전, 과거·능력 단서
4. 수탈·인간성·높은 유대 진엔딩
5. 진부함·설정붕괴 위험 5개와 보정

각 후보 2200 한국어 단어 이내. 구체적인 원인→행동→결과를 우선하라.
