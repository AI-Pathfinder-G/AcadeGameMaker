# MiniMax M3 작업 요청 — 인물 중심 재구축안 문맥 교정

뒤에 첨부되는 비정사 8챕터 서사 초안을 한국어 서사 편집자로 검토하라. 새 설정, 새 인물, 새 사건, 새 대사, 새 결말을 만들지 않는다. 이름·역할·동기·장별 사건·선택 결과를 바꾸지 않는다. GPT-5.6 Sol이 수용 여부를 결정한다.

다음만 검토한다.

- 감정 변화가 장면 없이 급하게 선언되는 부분
- 번역투, 해설투, 반복되는 문장 구조
- 대사가 인물의 말보다 주제 설명처럼 들리는 부분
- 도언과 세령의 애정·균열이 공식적으로 보이는 부분
- 도언의 광오함이 유치한 악역 연기처럼 보이는 부분
- 아인이 구출 대상이나 희생 도구로만 보이는 부분
- 라겐이 전형적인 질서·효율 악역처럼 보이는 부분
- 기승전결의 연결이 끊기는 부분

영향도가 높은 제안 최대 15개만 출력한다. 각 항목은 `위치 / 문제 / 최소 교정안 / 이유`로 작성한다. 교정안은 기존 문장의 삭제·축약·어순 변경을 우선하며, 새 대사는 만들지 않는다. 마지막에 `반드시 고칠 것 5개`와 `현재 강점 5개`를 적는다. 전체 1,800 한국어 단어 이내.
