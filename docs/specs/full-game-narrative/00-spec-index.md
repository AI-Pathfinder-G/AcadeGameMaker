# [NAR-00] Character-first Eight-chapter Narrative

- Status: Review
- Owner: Sol
- Unit design/implementation: Terra
- Verification: Luna
- Last updated: 2026-08-24

## Purpose

도언이 타인의 무게를 대신 짊어지는 장점을 그들의 선택까지 소유할 권리로 바꾸지 않도록 하는 인물 중심의 8챕터 서사를 구현하고 검증한다. 세령과의 관계, 라겐과의 개인적 대항, 아인의 거부권, 수탈과 연대의 유효한 성장 경로가 하나의 기승전결로 수렴해야 한다.

## Scope contract

### In scope

- 8챕터의 `기 1~2장 → 승 3~4장 → 전 5~7장 → 결 8장` 구조
- 도언·세령·라겐·아인의 동기, 관계, 선택권, 책임
- 세령과의 유대와 조건부 동행·결별
- 도언의 도덕적 갈등과 자기정당화형 `광오`
- 유대·핵심 약속·광오의 서사 상태 전환 규칙과 결말 자격
- 수탈·기본·진엔딩의 조건과 결과
- 최종장의 자발적 NPC 공명과 `각자의 아래`

### Out of scope

- 정확한 대사와 커트신 연출문
- 유대 수치·증감량과 광오 연출 튜닝의 수치 밸런싱. 서사 자격 상태와 전환 규칙은 범위에 포함한다.
- 챕터별 보스 전투 수치, 룸 배치, 애니메이션
- 사이드킥 지원 스킬의 exact 프로그레션
- Unity 씬·런타임 구현과 제작 일정

## Contract

### Inputs

- 챕터 진행 상태와 전환 이벤트
- 주체성 보존·수탈 선택 이력
- 세령과 맺은 핵심 약속의 지킴·위반 이력
- 유대 상태와 세령의 동행 여부
- NPC별 공명 제공 여부와 허용 범위

### Outputs

- 후속 챕터 또는 결말·에필로그의 인물·관계·세계 상태
- 도언의 말투·호칭·자세·전투 후 행동에 필요한 표현 단계
- 세령의 동행·이탈·결별 자격 상태
- 세 결말의 진입 자격
- 최종 자발적 공명과 `각자의 아래` 해금 자격

### Owned state

- 전체 챕터 진행도와 서사 분기 기록
- 핵심 약속 이벤트 기록
- `0~100` 유대도와 `경계 / 조건부 동행 / 신뢰 / 깊은 유대` 표시 상태
- 인물별 관계 상태와 공명 허용 상태
- `책임 / 독단 / 권리화 / 지배 / 절대` 광오 0~4단계와 비가역 `humanityUnbroken` 상태

### Verification paths

- **주체성 보존 경로:** 모든 중대 선택에서 당사자의 거부와 허용 범위를 지킨 기준 이력.
- **수탈 경로:** 모든 중대 선택에서 강제 추출·절차 생략·각인 귀속 중 제공된 수탈 결과를 택한 기준 이력.
- **혼합 경로:** 챕터별 선택·생존자 매트릭스가 정하는 대표 선택 벡터. OD-NAR-003 해결 전에는 검증 fixture로 사용하지 않는다.

### Invariants

- 도덕·인간성·광오를 직접 표시하는 점수 게이지를 노출하지 않는다.
- 광오는 외부 조종이 아니라 도언의 선택과 자기정당화에서 발생한다.
- 광오 단계는 서사 저장 내에서 낮아지지 않고 UI에 exact 수치를 노출하지 않는다. `humanityUnbroken`은 최초 유효 수탈 선택 확정 후 해당 플레이에서 복구되지 않는다.
- 주체성 보존과 수탈은 모두 런과 전투를 완주할 수 있는 서로 다른 스킬군을 제공한다.
- 세령은 보상물, 도덕 해설자, 자동 면책 수단이 아니다.
- 높은 유대는 진엔딩의 필요조건이지만 인간성 보존과 NPC의 자발적 공명을 대체하지 않는다.
- 유대도 exact 수치는 UI에 노출하지 않고, 약속 위반은 높은 유대도로 자동 상쇄하지 않는다.
- `손대지 않는다 / 숨기지 않는다 / 붙잡지 않는다` 세 핵심 약속은 각각 신체의 주체성, 진실을 알 권리, 떠날 권리를 보호하며 모두 지켜져야 진엔딩 자격을 얻는다.
- 약속 위반은 사고·실패·미지의 정보가 아니라 강제 사용·의도적 은폐·강제 구금을 플레이어가 명시적으로 선택했을 때만 발생한다.
- 약속 위반 없는 관계 균열은 7장 전 행동적 복원으로 사이드킥·진엔딩 자격을 회복할 수 있다. 약속 파기는 사이드킥과 진엔딩을 영구적으로 닫고 유대도 상한을 74로 고정하지만, 7장의 독립 협력자 재합류로 메인 서사 진행은 복구할 수 있다.
- 세령과 NPC는 진보스전을 대신 수행하지 않는다. 자발적 공명은 절대 하방을 무효화할 조건을 만들고 라겐과의 전투는 도언이 직접 수행한다.
- `각자의 아래`가 성립한 도시 상태에서는 어떤 단일 주체도 다른 주체의 하방 방향을 강제로 재지정할 수 없고, 공명은 NPC별 허용 범위를 초과해 소비하지 않는다.
- 1챕터는 VD-06의 유담·오르단·세령 첫 등장 계약을 보존한다.

## Requirements

- **REQ-NAR-001:** 전체 서사는 정확히 8개 챕터로 구성하고 `기 2개, 승 2개, 전 3개, 결 1개`로 역할을 분배한다.
- **REQ-NAR-002:** 도언·세령·라겐·아인은 각자 독립된 목표와 거부권을 갖고, 모든 챕터의 핵심 사건은 이들 중 두 명 이상의 관계 또는 책임 상태를 변화시킨다.
- **REQ-NAR-003:** 도언과 세령의 관계는 `추적자와 표적 → 조건부 거래 → 불편한 신뢰 → 애정 → 균열 → 사랑과 거부의 동시 존재 → 동행 또는 결별`의 원인과 결과를 플레이 결과에 따라 표현한다.
- **REQ-NAR-004:** 각 주요 선택은 주체성 보존과 수탈 결과를 둘 다 유효한 진행 경로로 제공하되, 획득 스킬의 성격·전투 효율·관계·후속 공명에 다른 결과를 남긴다.
- **REQ-NAR-005:** 수탈 선택이 누적될수록 도언은 `내가 대신 짊어진다 → 물을 시간이 없다며 절차를 생략한다 → 내가 가장 많이 희생했으니 내가 가장 잘 안다 → 내가 결정하고 감사·복종을 요구한다 → 선택권 자체를 없앰다`의 캐논 사다리를 말투·호칭·자세·행동으로 관찰 가능하게 드러낸다.
- **REQ-NAR-006:** 중대한 선택은 해당 챕터 내의 대사 차이에 그치지 않고 후속 챕터 또는 결말·에필로그의 인물 행동, 세령의 경계, NPC 공명, 또는 결말 자격 중 하나 이상을 변경한다.
- **REQ-NAR-007:** 게임은 인간성 포기, 기본, 진엔딩의 세 결말을 제공하고 진엔딩은 인간성 보존·핵심 약속·충분한 유대·필요 NPC의 자발적 공명을 모두 요구한다.
- **REQ-NAR-008:** 인간성 포기 결말에서 도언은 라겐보다 강한 단일 하방의 주인이 되고, 세령은 유대 상태와 관계없이 떠난다.
- **REQ-NAR-009:** 진엔딩에서 NPC들은 각자 허용한 범위만 공명해 `절대 하방`을 무효화하며, 도언은 여러 주체가 서로 다른 아래를 선택해도 하나의 도시를 지탱할 수 있게 하는 `각자의 아래`를 얻는다.

## Acceptance criteria

### AC-NAR-001 — 8챕터 기승전결 감사

- **Given** 모든 챕터의 시놉시스와 스토리 상태 표가 있고
- **When** 챕터 수, 기승전결 역할, 핵심 사건의 인과, 관계 변화를 감사하면
- **Then** 정확히 8개 챕터가 2/2/3/1로 분류되고 각 챕터가 중심 인물 두 명 이상에 후속 챕터 또는 결말·에필로그에서 추적 가능한 관계 또는 책임 상태 변화를 남긴다.

### AC-NAR-002 — 인물과 관계 아크 감사

- **Given** 네 중심 인물의 목표·거부권·책임과 도언–세령 관계 이벤트가 있고
- **When** 주체성 보존, OD-NAR-003에서 확정한 혼합, 수탈 경로를 비교하면
- **Then** 세 경로 모두에서 세령·라겐·아인이 도언의 목표를 위한 도구로만 처리되지 않고 각자의 선택이 후속 상태를 바꾼다.

### AC-NAR-003 — 유효한 선택 경로

- **Given** 주체성 보존과 수탈 선택을 각각 고정한 두 테스트 플레이가 있고
- **When** 모든 필수 전투·이동·사건을 진행하면
- **Then** 두 경로 모두 완주 가능하고 다른 스킬군·효율·관계·공명 결과를 제공한다.

### AC-NAR-004 — 광오의 인과와 가시성

- **Given** 선택 이력만 다른 동일 챕터 상태들이 있고
- **When** 도언의 말투·호칭·자세·전투 후 행동과 세령의 반응을 비교하면
- **Then** 수탈 누적 경로만 자기정당화가 단계적으로 심화되며 외부 존재의 조종으로 설명되지 않는다.

### AC-NAR-005 — 챕터 간 결과 지속

- **Given** 각 중대 선택의 직후 상태와 후속 챕터 또는 결말·에필로그 상태가 있고
- **When** 선택별 영향을 추적하면
- **Then** 모든 중대 선택이 후속 챕터 또는 결말·에필로그의 인물 행동, 세령의 경계, NPC 공명, 결말 자격 중 하나 이상에 재현 가능한 변화를 남긴다.

### AC-NAR-006 — 결말 자격 매트릭스

- **Given** 인간성 보존, 핵심 약속, 유대, NPC 자발적 공명의 충족·미충족 조합이 있고
- **When** 최종장 진입 자격을 평가하면
- **Then** 모든 조합이 정의된 세 결말 중 하나로만 결정되고, 높은 유대만으로 진엔딩이 열리지 않으며, 인간성 포기 결말에서는 세령이 반드시 떠난다.

### AC-NAR-007 — 진엔딩 최종 전투 연출

- **Given** 진엔딩 자격을 충족한 최종장이 있고
- **When** NPC들이 공명을 제공하고 도언이 `각자의 아래`를 사용하면
- **Then** NPC들은 자신이 허용한 힘만 모아 절대 하방을 무효화하고 전투 대상을 직접 공격하지 않으며, 공명 소비량이 각 NPC의 허용 범위를 넘지 않고, 어떤 단일 주체도 다른 주체의 하방을 재지정할 수 없으며, 권능을 잃은 라겐과의 전투는 도언이 직접 완수한다.
