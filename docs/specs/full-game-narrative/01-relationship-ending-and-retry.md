# NAR-REL — 관계·진엔딩·CH7 재도전 계약

- Status: Review. 2026-09-09 Astra 초안. 사용자 방향 승인 ADR-0030, 구현 승인 아님.
- 근거: [NAR-00](./00-spec-index.md), [별도 보고](../../proposals/2026-09-09-relationship-ending-and-tragedy-report.md).
- 입력: 확정 선택, 관계/유대, 약속과 중요 신뢰 이력, humanityUnbroken, NPC별 허용 공명, 전투/저장 완료.
- 출력: 관계 변화, 진보스 입장 자격/결말 경로, CH7 재개 상태.
- 소유: 불가역 서사 이력은 서사 계층, transient snapshot은 전투 계층, 원자 커밋은 저장 계층. 실제 타입/이벤트 ID는 후속 작업 계약에서 고정.
- 비범위: 런타임·그림·전투 수치·완성된 생존 매트릭스.

## 요구사항

- REQ-NREL-001: 자격은 인간성 유지·세 약속·bond>=75·핵심 신뢰·상호 성립한 현재 연애·필요 자발적 공명·최종 점유 거부의 AND다. 자격은 승리가 아니며 진보스를 직접 격파해야 한다.
- REQ-NREL-002: 중요 신뢰 파기는 예고된 의도적 사건에만 적용하고 비가역이다. 일상 의견 차이/전투 실패/미지 정보는 파기가 아니다. 낮은 유대 회복은 핵심 신뢰나 약속 파기를 지우지 않는다.
- REQ-NREL-003: 연애는 상호 확인으로 성립한다. 점수·선물·구조 성공만으로 성립하지 않는다. 약속 파기는 즉시 사이드킥 이탈/연애 영구 폐쇄/유대상한74. 부재/독립 협력자는 연인으로 간주하지 않는다.
- REQ-NREL-004: CH7 선택·불가역 결과·후반전 시작 정보는 한 저장 커밋으로 확정한다. 동일 분기 재도전은 전투/주민 진행을 시작 snapshot으로 복원하되 이력 유지, 보상 중복 없음. 저장 실패는 이전 안정 상태를 유지하고 새 결과를 확정하지 않는다.
- REQ-NREL-005: 필연 희생자 사망은 인간성/관계 실패/진엔딩 폐쇄/스킬 보상이 아니다. 해당 인물을 필수 생존 공명 제공자로 지정하지 않는다. CH4 손상된 아인의 완전 각인을 CH6에서 복구하거나 재수탈 보상을 지급하지 않는다.
- REQ-NREL-006: 상점은 연인의 일시 동행 부재로 구매 제한을 우회할 수 없다. 거래는 관계/인간성 복구 수단이 아니다. 다른 관계의 우선순위는 별도 상점 계약에서 고정한다.

## 인수 기준 — 미실행

- AC-NREL-001 → REQ001: 모두 true일 때 입장만 허용, 각 조건 하나씩 false이면 불허. 진보스 패배는 엔딩 승리 아님.
- AC-NREL-002 → REQ002/003: bond80/연인도 중요 신뢰 파기 후 자격 영구 불가. 일상 갈등만 있었던 온전한 신뢰는 회복 후 다른 조건 충족 시 가능. 스킵/미지 정보/피격으로 파기하지 않음.
- AC-NREL-003 → REQ003/006: 비연애·연인·일시 거리·영구 결별·독립 협력·부재별 자격/동행/상점 결과 구분. 연인 단독 방문 구매 불가. 독립 협력은 연애/사이드킥 복구 아님.
- AC-NREL-004 → REQ004: 선택 전/쓰기 도중/커밋 후/스킬 표시 후/후반전 사망에 중단 주입. 이전 안정 상태 또는 완전 커밋된 같은 분기 시작 상태 하나만 복원. 부분 불가역 결과/보상 중복/선택 화면 우회 없음.
- AC-NREL-005 → REQ005: 모든 대표 경로에서 사망/미완 소망 유지, 사망만으로 자격 변화 없음. 아인 손상은 CH6까지 지속되고 동일 각인 보상 재지급 없음.

## Approved 전환 전

중요 신뢰 사건 exact 목록, 상호 고백/거절/재확인 경계, NPC 공명/생존 상태표, 저장 snapshot/실패 프로토콜, 관계-상점 우선순위, 독립 검토 증적 필요. 기존 수직 데모 저장 계약은 수정하지 않는다.
