1. 현재 소스는 최종 준비 원장의 실제 루트·정확 상대 경로·SHA에서 열거한다. 약20이라는 숫자나 잘못된 기준 루트를 선입력하지 않는다. 아직 편집 중인 소스는 최종 지문 미정으로 기록한다. 최종 준비20 집합이 확정되기 전 v2를 최종 원장으로 발급하지 않는다. 역사193소스/1084입력과 현재 소스는 역할을 구분한다.
2. 실제193소스·다섯 후속 QA·아홉 선택 및 그 보조의 읽기 호출에서 출발하여 원문 위치·호출 종류·대상 경로·원시SHA를 연결한다. 문서/역사/선택/미디어 접두사만으로 제외하지 않는다. 시험이 실제 읽는 역사 승인·검수 문서와 과거 selector도 실행 필수 입력으로 보존한다. 직접 읽기뿐 아니라 메타/GUID·조립·Resources/직렬화·패키지·도구 연쇄의 간접 의존을 분리한다.

4. 최종 정확 집합의 중복·누락·대소문자 충돌·루트 이탈·실제 존재/SHA·분류 합계와 읽기 변의 대상을 기계 대조한다. UTF-8 엄격 디코딩·JSON 왕복 파싱 및 대표 한글 설명의 원문 일치를 확인한다. 한글을 다시 해석해 복원한 것처럼 꾸미지 말고 현재 조사 내용에서 올바른 문자열을 작성한다.
