# 저장소 정규화 원장의 엄격 대조 검사기

상태: **Approved**, 2026-10-02 아스트라 역할 승인. 사용자 기술 판단 위임과 [솔의 새 회귀 설계 초안](../../proposals/2026-10-02-canonical-regression-freeze-design.md)에 따른 선행 검사기 구현이다. 후속 fixture 변경·선택 재발급·Unity 실행은 별도 계약이다.

구현 역할의 별도 `gpt-6-sol`이 새 `qa/tools/Test-PublicationCanonicalBaseline.ps1` 하나를 구현한다. 기존 제품·시험·QA 도구·원장·505/534 후보·역사 증거는 수정하지 않는다. 검사기는 반드시 원장 경로·예상 원장SHA·원본 루트·후보 루트·예상 행수를 명시적으로 입력받는다. 원장 원시 바이트SHA를 먼저 비교하고 그 뒤 JSON을 읽는다. 정확 고유 상대경로, 루트 이탈/절대경로/부모이동/.git 경로 거절, 전체·행별 다섯 거짓 수용 플래그, 정확 후보 파일 집합을 검사한다. 두 루트와 대상/열거 경로의 모든 하위 성분에서 재분석 지점·심볼릭 링크·접합점을 읽기 전에 거절한다. 정규화 후 및 대소문자 무시 중복도 거절한다. 예상 행수·지문·루트를 자동 추론하거나 고치지 않는다. 누락·중복·뜻하지 않은 후보 파일은 실패다.

각 행의 `Path`, `OriginalSha256`, `CandidateSha256`, `OriginalBytes`, `CandidateBytes`, `OriginalGitBlobOid`, `RepositoryFilteredGitBlobOid`, `CandidateGitBlobOid`, `Transition`, `CrLfPairsConverted`를 실제 바이트와 대조한다. 지문은 원시 바이트SHA-256, Git 객체는 `blob <바이트수>\0` 접두사를 결속한 SHA-1로 계산한다. 외부 Git 쓰기나 필터 실행은 필요 없다. `Transition=없음`이면 바이트가 전부 같고 CRLF 변환수0이어야 한다. `CRLF→LF`이면 원본 바이트에서 정확 `0D 0A` 쌍의 `0D`만 제거한 결과가 후보와 바이트 단위로 같고 실제 변환수와 기록수가 같아야 한다. 다른 전이·인코딩 재해석·전체 개행 재생성·기록된 두 끝SHA로 다른 내용을 합법화하는 방식은 실패다. 후보 Git 객체와 원장의 저장소 필터 객체가 정확 같아야 한다. 원장의 출처 권한·현재 Git 속성 자체를 새로 승인한다고 주장하지 않는다.

`-SelfTest`는 별도 새 `output/publication-canonical-validator-selftest-v1` 안의 합성 입력만 사용한다. 무변환·CRLF→LF 정상 사례와 원장SHA 변조, 후보 한 바이트 변조, 두 끝SHA를 갱신한 의미 변경 전이, 중복경로, 후보 밖 파일, 수용 플래그 참, 대소문자 경로 중복, 재분석 지점의 여덟 거절 사례를 각각 실제 검사기로 확인한다. 링크 음성은 합성 루트 안의 새 디렉터리만 대상으로 삼고 외부 경로에 링크하지 않는다. 접합점 생성이 지원되지 않으면 그 실제 오류와 해당 사례 미실행을 기록하고 자체 검사 성공으로 표시하지 않는다. 부정 사례 통과는 자체 검사의 실패다. 지정 합성 경로 밖 바이트를 쓰거나 기존 디렉터리를 덮어쓰지 않는다. 합성 시험을 Unity·제품 시험 또는 독립 검수로 해석하지 않는다.

505 원장 SHA `9E23DCFBFAA7C1B3C2AE006FBD6BDEC58F456974E7C4C878E9F38416C654762C` 및 [변환수 보완 계약](2026-10-02-lf534-transition-count-supplement.md)의 완성된534 v2 원장의 정확 발급SHA를 명시해 각 후보 검사를 한 번씩, 자체 검사를 한 번 수행한다. stdout·실제 종료값·입력 전후 지문·검사기SHA를 `artifacts/c4-canonical-baseline-validator-v1.json`, 같은 이름 `.md`, `docs/verification/2026-10-02-canonical-baseline-validator-terra-report.md`에 기록한다. 534 v2 원장이 미완성 또는 자체 지문 불일치면 해당 실행 전에 중단한다. 모두 다섯 수용 플래그는 거짓이다. 네트워크·Unity·Git 쓰기·게시·역사pin 변경은 금지한다.
