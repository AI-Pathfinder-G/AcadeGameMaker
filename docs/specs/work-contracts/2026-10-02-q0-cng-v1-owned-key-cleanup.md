해당 한 이름의 공개키 매개변수만 읽어 기존 정규 공개키 지문을 재계산한다. 정확 일치하고 키 형식/크기도 일치할 때만 이 시험이 생성한 객체에 CngKey.Delete를 호출한다. 타 키·다른 지문이면 삭제하지 않고 불일치로 보고한다. 명확한 키 미존재 오류면 해당 이름/제공자 조회의 부재만 기록하며 시스템 모든 키 부재로 확장하지 않는다. API가 이름을 거절하거나 다른 오류이면 정리 미입증으로 기록한다. 개인키 내보내기/본문 조회/파일 삭제는 금지한다.

삭제한 경우 같은 정확 이름 재조회에서 명확한 미존재 응답을 확인하고 객체를 폐기한다. 실제 실행 권한·오류코드·공개지문 일치 여부와 정리 결과만 기록한다. 제한 환경 거절이면 같은 승인된 작업의 권한 경로를 한 번 사용할 수 있으나 오류 반복이나 추가 이름 탐색은 금지한다. 소스/결과 지문과 기존 v1/v2 보호를 기록하며 실사용 발급/권위 P1 수용/원격/Git/제품 변경은 금지한다. 독립 검수는 별도다.
