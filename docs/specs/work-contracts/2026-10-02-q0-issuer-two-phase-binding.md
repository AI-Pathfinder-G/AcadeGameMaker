# Q0 공개키 동결 후 권위 일회 결속

상태: **Approved**, 2026-10-02 통합 책임자 승인. `REQ-PLAT-068..070`, `AC-PLAT-067/068`의 합성 발급 세션 후속 구현이다. v1은 합성 시험20개를 구현했지만 생성 때 권위 SHA를 요구한다. 실제 발급 순서는 키 생성→검증 소스 동결→권위 기록 발행→원격 확인이므로 생성 때 미래 권위 SHA를 정할 수 없다. 임시 가짜 SHA를 실사용으로 바꾸지 않고 두 단계로 분리한다.

테라 허용 새 출력은 `qa/tools/Q0EphemeralIssuerV2.Core.psm1`, `qa/tools/Test-Q0EphemeralIssuerV2Core.ps1`, `artifacts/c4-q0-ephemeral-issuer-core-tests-v2.json`, `docs/verification/2026-10-02-q0-ephemeral-issuer-core-v2-terra-report.md`이다. v1과 기존 엄격 검증기·제공자/정리 증거는 불변이다.

새 세션은 계약 SHA·현재 문맥·단조 TTL만 고정하고 공개키 정보를 제공한다. 아직 권위 미결속 상태에서는 서명을 반드시 거절한다. 별도 명시 함수가 같은 살아 있는 세션에 정확 대문자 권위 SHA를 한 번만 결속한다. 두 번째 결속은 같은 값이어도 거절한다. 결속 뒤 공개키/계약/문맥은 변하지 않으며 권위 변경이나 새 키로 교체하는 함수는 없다. 결속은 신뢰된 통합 책임자가 인증 커넥터의 불변 원격 기록을 대조한 뒤 수행해야 한다는 후속 운영 경계이며 이 합성 모듈 자체가 외부 진위를 인증한다고 주장하지 않는다.

기존 CNG 실제 null/IsEphemeral/ExportPolicyNone·SHA/nonce·단조 만료·한 번 서명/재사용/폐기·공개 검증을 유지한다. 추가 시험은 미결속 서명 거절, 일회 결속, 재결속/권위 변경 거절, 결속 전후 동일 공개키, 만료/폐기 뒤 결속 거절을 포함한다. 동일 소스 세션에 실제 미래 권위 SHA나 가짜 발급 성공을 넣지 않는다. 합성 키만 실제 실행하고 개인키 내보내기/저장/로그/복원은 금지한다. 자기 결과 독립 수용은 금지하며 실사용 키·계획·원격·Git·제품·534/505 변경은 허용하지 않는다.
