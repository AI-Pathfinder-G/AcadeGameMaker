UTC 시작→저장소 기본 가지→가지HEAD→Git 커밋 객체의 `tree.sha`→정확 트리 객체 전체 재귀응답→501 집합 내 존재 blob 전부→HEAD 재확인→UTC 끝으로 새 관측을 만든다. 커밋ID·treeID·blobID를 다른 필드에 명시한다. 커밋응답 `tree.sha`와 트리응답 `sha`가 일치하지 않거나 트리가 잘렸거나 HEAD가 바뀌면 성공으로 판정하지 않는다. 각 blob 본문은 Base64로 보관하고 실제 SHA256·크기·Git blob SHA1을 응답/트리와 대조한다.

새 출력은 `artifacts/c4-content-survey-remote-objects-v2.json`, `docs/verification/2026-10-02-content-survey-remote-correction-terra-report.md` 두 파일이다. 커밋/트리 응답의 근거 구조, 원격 존재/부재 정확501 집합, 원문과 정규화 충돌 별도 목록을 기록한다. 현재 원문501 시작·끝 지문도 대조한다. 전체501 내용/간접 의존 재검수와 게시 허용은 아니다. 모든 승인 플래그는 거짓이다.
