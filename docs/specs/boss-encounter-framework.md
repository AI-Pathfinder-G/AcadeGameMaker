# BOSS-F — 보스전 구성 기준

- Status: Approved (design constraints only; not runtime implementation authorization)
- Approved: Astra, 2026-09-08, explicit user direction / ADR-0028
- Updated: 같은 날 후속 사용자 정정으로 진보스 이벤트전 해석 철회, 고난도 숙련 결전·REQ008..011/AC005..007 추가. 디자인 제약만 승인하며 런타임 구현 권한은 확장하지 않는다.
- Scope: 초반·중반·최종 보스전·진보스전의 전장과 공략 역할 구분. 수치/형상/장치 수명주기/실패·재시도 구현은 별도 Approved 작업 계약이 필요하다.
- Authority: [보스전 캐논](../canon/boss-encounter-direction.md), [ADR-0028](../adr/0028-boss-arena-escalation-and-final-duel.md). 기존 NAR-00 Review 상태와 미결정은 유지한다.

## 요구사항

- REQ-BOSSF-001: 초반 오르단 전투는 기존 지형과 전투 거리를 유지하는 한 화면형으로 저작한다. 넓은 카메라 시야의 남는 공간을 추가 전투 영역으로 오인시키지 않는다.
- REQ-BOSSF-002: 중반 전투는 복수 기믹과 높아진 전투 난이도에 맞춰 플레이 가능한 전장을 확장한다. 카메라 줌아웃만으로 확장했다고 간주하지 않는다.
- REQ-BOSSF-003: 최종 보스전은 거대한 보스와 최소 두 개의 구별 가능한 페이즈를 갖는다. 보스가 발사한 중력 장치를 플레이어가 공략에 활용해야 하며 단순 피해 투사체만으로 대체하지 않는다.
- REQ-BOSSF-004: 최종 보스전의 고피해 공격은 관찰·학습 가능한 패턴으로 회피와 대응을 요구한다. 정확한 피해량·예고 길이·회피 구간·재시도는 아직 정하지 않는다.
- REQ-BOSSF-005: 진보스전은 기존 서사의 라겐이 권능을 잃은 뒤의 직접 결전이다. 새로운 독립 보스·악령·외부 조종을 추가하지 않는다. 자발적 NPC 공명과 각자의 아래로 봉인한 절대 하방 및 그에 의존하는 장치 기믹을 전투 중 무단 복원하지 않는다.
- REQ-BOSSF-006: 진보스전은 좁은 거리에서 공격 기회와 방어 대응을 판단하는 도언의 직접 조작 전투로 구성한다. NPC 직접 공격·자동 승리·기술 삭제·강제 피격을 이 방향의 승인으로 추론하지 않는다. 기존 인간성·유대·핵심 약속·공명 허용 범위와 엔딩 자격을 유지한다.
- REQ-BOSSF-007: 봉인 완료는 보상 지급·선택 저장·Run 성공 완료와 별개의 사실이다. 수직 데모에는 후반 보스/봉인/진보스 구현을 추가하지 않는다. 고정 배율·해상도·조준 계약은 그대로 유지한다.
- REQ-BOSSF-008: 진보스전은 이벤트전이 아닌 최종 보스전보다 높은 실행 난이도의 숙련도 결전으로 설계한다. 진엔딩에 합법적으로 도달하는 상대적 저파괴력 연대 기술·성장 구성으로도 숙련된 플레이어가 승리할 수 있어야 하며 수탈 전용 기술이나 중력 편법을 요구하지 않는다.
- REQ-BOSSF-009: 패턴은 식별 가능한 예고·빠른 연격/지연타·거리 압박·공격 회수·명확한 대응 기회를 통해 학습과 실행을 시험한다. 구석 압박에서도 합법적 대응이 남아야 하며 무적 대시/새 패링을 가정하거나 강제 피해·체력 증가만으로 목표 난이도를 충족하지 않는다. 구체 조합/타이밍은 별도 계약에서 고정한다.
- REQ-BOSSF-010: 중력 편법 배제는 장치 역이용·영구 구속·안전지대 악용 등 전투를 무력화하는 경로와 정상 기술 사용을 구분해 명시한다. 모든 중력 기술의 일괄 삭제로 해석하지 않는다. 축적한 레벨·성장과 조작 숙련이 각각 승리에 기여해야 하며 정확한 레벨 제도/입장 문턱/기술 제한은 후속 계약 사항이다.
- REQ-BOSSF-011: NPC 공명이 절대권능을 무력화해 전투 기회를 만들고 도언이 자신의 능력으로 승리를 완수하는 인과를 표현한다. NPC의 기여를 지우지도, NPC 직접 공격이나 자동 승리로 플레이어의 성취를 대체하지도 않는다.

- 추가 요구사항 **REQ-BOSSF-012** (2026-09-08 사용자 후속 지시, 설계 제약만 Approved): 동일 캐릭터로 두 번 이상 구성하는 보스는 최대 한 개체로 제한하고 다른 챕터 대표 보스는 서로 다른 인물/생물로 구성한다. 실패 재시도와 새로운 서사 전투를 구별하며, 강화형/클론으로 제한을 우회하지 않는다. 구체 가칭·생물·장비와 신규 전투 구현은 별도 승인 대상이다.

## 인수 기준 — 설계 감사와 후속 구현 추적

- **AC-BOSSF-008 → REQ012:** 보스 전투 ID를 실제 캐릭터 정체성 ID에 대응시켜 반복 캐릭터가 최대 한 개체인지 문서 검토한다. 새 보스가 기존 보스의 이름/외형만 바꾼 복제인지도 서사·장비·공격 역할로 확인한다. NPC 대화 재등장은 전투로 세지 않고 별도 표시한다.

- AC-BOSSF-001 → REQ001/002: 초반·중반 설계에 실제 플레이 경계와 화면 경계를 구분해 표시하고, 오르단 지형 보존 및 중반 확장 공간의 기믹 용도를 검수한다.
- AC-BOSSF-002 → REQ003/004: 최종 보스 설계에서 최소 두 페이즈의 서로 다른 행동과 발사 장치 활용 경로, 고피해 예고·회피 대응을 식별한다. 체력바만 새로 채우는 동일 페이즈 반복은 충족하지 않는다.
- AC-BOSSF-003 → REQ005/006: 진보스 진입 전 공명 제공자의 동의 범위, 봉인되는 권능/장치 목록, 라겐과 도언의 직접 결전으로 이어지는 인과를 확인한다. 봉인된 기믹의 재사용·NPC 대리 공격·기술 박탈이 없어야 한다.
- AC-BOSSF-004 → REQ006/007: 기존 엔딩 자격과 NPC 허용 범위를 변경하지 않고, 봉인과 Run/보상/선택 커밋을 분리하며, 문서 승인을 실제 전투/시각 검증 완료로 표시하지 않는다.
- AC-BOSSF-005 → REQ008/009/010: 후속 Approved 성장 범위의 진엔딩 가능 연대 기술 구성으로 숙련도별 반복 플레이를 비교한다. 숙련된 조작의 승리 경로, 레벨/성장 준비의 기여, 패턴 학습에 따른 회피·공격 기회 활용 개선을 입증한다. 수탈 전용 기술·중력 편법·과도한 레벨 노가다를 필수 해법으로 삼지 않고, 최종 보스보다 높은 실행 요구를 별도 난이도 검수 지표로 확인한다. 아직 수치 목표나 실제 통과 결과는 없다.
- AC-BOSSF-006 → REQ009/010: 각 패턴·연계·구석 압박에서 예고와 대응 가능 구간을 재현하고, 합법적 기술 사용과 배제할 편법을 분리한 목록으로 검수한다. 전투 불능 무한 구속, 피할 수 없는 연계, 봉인된 장치의 재가동이 없어야 한다.
- AC-BOSSF-007 → REQ005/011: NPC 동의와 공명 → 권능 무력화 → 도언의 직접 조작 승리 순서를 확인한다. NPC 도움과 도언의 성취가 모두 드러나고 자동 승리·NPC 직접 피해로 대체되지 않아야 한다.

현재는 디자인 제약이 Approved일 뿐 위 AC의 실제 전투 검증은 완료되지 않았다. 후반 구현 전 페이즈 전환, 장치 소유/생성/제거, 정확한 전장·수치·실패 경계를 고정하고 독립 검증한다.
