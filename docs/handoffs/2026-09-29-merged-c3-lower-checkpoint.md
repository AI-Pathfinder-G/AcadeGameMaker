최신 상태: 상위 일관 단위 초기 동결과 독립 C# 컴파일 네 건의 종료 0을 확인했으나 Unity 실행은 아직 하지 않았다. 초기 14개 지문 원장 `0849AE5B55FDD448175A3534CB2A6E67F36102257FDFA8FEA27C0D39DAEF1175`에서 솔·루나가 늦은 실제 예약 재사용을 발견했고, 루나 추가 검수는 필수 분류·결정 음성·실제 파일 재관찰 시험 누락을 더해 P0=0/P1=4다. ## 실행과 재개 순서

환경 사전 확인은 통과했다. 아스트라는 고정 소스에서 새 하위 10개와 기존 관찰 11개의 실제 Unity 집중 검사를 실행했다. 실행 선택·전후 입력·로그·결과는 `artifacts/c3-lower-r1-*`로 보존하며 실제 종료와 대조 결과는 별도 실행 기록이 권위를 갖는다. 이 실행에는 상위 Q-B 출처·결정 경쟁·취소 재무장·C4가 포함되지 않는다.

[실제 집중 결과](../verification/2026-09-29-c3-lower-r1-focused-execution.md)는 21/21 통과·종료 코드 0이다. 실패·건너뜀·판정 불가와 선택 이름·전후 입력 876개 지문 차이는 모두 0이다. 해당 소유 Unity 프로세스는 종료됐다. 보정 후 독립 검수와 필수 회귀 전이므로 하위 또는 상위 전체 수용으로 승격하지 않는다.

1. 모델 사용 가능 상태가 바뀐 뒤 테라의 보정 완료 여부와 모든 남은 음성 행을 확인한다. 할당량 오류 상태에서 반복 호출하거나 별도 유료 경로로 전환하지 않는다.
2. 최신 하위 정확 지문을 루나가 독립 검수한다. 실제 결과와 P1 폐쇄를 대조하고 하위 수용 범위만 아스트라가 결정한다.
3. 최신 Q-B 제안의 최초/후속 세대 조건, 실제 참조 입력 및 생성자 구현 가능성을 독립 검수한 뒤 아스트라가 내부 진입점 보정을 승인한다. 값만으로 발급 참조를 찾거나 자동 선택하는 진입점은 금지한다.
4. 테라가 승인된 Q-B·새 소유자·presenter 재무장 일관 단위를 구현한다. 기존 최초 요청·의도와 이력을 보존하고 후속 세대 슬롯만 새로 만든다. 실제 cursor의 첫 유효 프레임은 해석 없이 폐기한다.
5. 루나 독립 검수, 실제 집중 및 필수 편집/실행 모드 회귀와 정확한 전후 지문 대조 후 아스트라가 ADR-0036의 C3 선행 범위를 수용한다.

C3 전체 AC-M5D7QC3-007/008은 Open/Not Verified를 유지한다. 전체 AC-010과 상위 소유자·재무장은 미수용이다. C4는 Review이며 identity 추출·실제 C1 Begin·C2·실행 보고·장면/맵/실제 UI 연결을 미리 구현하지 않는다. 기존 C3L 수용은 선행 정확 지문 증거로 보존하고 새 소스 전체 수용으로 재사용하지 않는다. 사용자 승인 읽기 전용 조회 함수나 원격 병합을 다시 승인받을 필요는 없다.
