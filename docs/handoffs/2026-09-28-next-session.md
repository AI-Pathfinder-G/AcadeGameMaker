- 검증 실행은 `qa/tools/Invoke-UnityQa.ps1`을 사용한다. 프로젝트 고정
  Unity 버전은 `6000.6.0f1`, 마지막 환경 검사는 로그인·라이선스를 통과했다.
  새 세션에서는 현재 상태를 재확인하되 성공을 가정하거나 설치·인증 설정을

- 껍데기 실행기가 먼저 끝나도 실제 소유 Editor가 살아 있으면 실패로
  판정하거나 새 Editor를 중복 실행하지 않는다. 결과 XML·검사 수·실제
  종료·예상 검사명·입력 전후 지문을 함께 확인한다. 관련 프로세스를 임의로
  종료하지 않는다.
- 이름공간의 넓은 제외 정규식은 부모 검사 선택 때문에 제외 사례를 다시
  포함시켰다. 실제 개별 시험 묶음의 끝 점을 포함하는 양의 접두 선택을
  사용하고 실행 전에 예상 검사명을 독립 검수한다. 4개 수동 프로세스 단계는
  일반 회귀 실행과 분리하며 필요한 실제 단계 정보를 제공한다.
- 입력 목록은 코드뿐 아니라 실제 저작 자료·설정·QA 작업기 소스와 프로젝트

  소급하지 않는다. 바뀐 코드에는 새 증거가 필요하다.

  오류와 다르다. 거절된 파일 변경을 다른 도구로 우회하지 않는다.
