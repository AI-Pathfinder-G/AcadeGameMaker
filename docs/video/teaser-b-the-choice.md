# Teaser B — 손대지 않는다

## 기획안

서사 차별점을 보여 주는 15초 선택 티저. 유담의 각인을 강제로 잘라내는 손과, 동의 범위를 확인한 뒤 공명선을 남기는 손을 같은 구도에서 대비한다. 어느 쪽도 게임 오버나 즉시 보상처럼 연출하지 않는다. 마지막은 선택 결과가 도언의 몸과 도시의 구조에 서로 다른 흔적을 남기는 이미지로 끝낸다.

핵심 연출어는 `거부 → 멈춤 → 두 갈래의 힘`이다. “인간성을 선택하면 약해진다”는 오해를 피하기 위해 연대 경로도 강하고 실용적인 공간 변화를 보여 준다.

## 쇼트 플롯

1. 0.0–3.0초: 유담의 신경계 안에 저장된 여러 시민의 중력 서명이 황동선처럼 맥동한다. 유담은 손을 들어 거부한다.
2. 3.0–6.0초: 도언의 손이 각인에 닿기 직전 정지한다. 세령의 시선이 프레임 가장자리에 들어오지만 대사를 하지 않는다.
3. 6.0–10.8초: 화면이 같은 공간의 두 겹 이미지로 분기된다. 한쪽은 붉은 수탈색으로 선을 절단해 압박파를 만들고, 다른 쪽은 청록·아이보리 공명선이 여러 발판을 연결해 공동 기준면을 만든다.
4. 10.8–15.0초: 두 결과가 도시의 서로 다른 구조를 움직인다. 도언은 힘을 얻지만 카메라는 얼굴보다 손과 남겨진 선을 보여 준다. 검은 화면으로 절단.
