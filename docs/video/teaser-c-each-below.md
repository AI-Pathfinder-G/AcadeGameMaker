# Teaser C — 각자의 아래

## 기획안

장기 비전을 위한 15초 브랜드 티저. 8챕터의 끝에서 라겐의 절대 하방과 도언의 선택이 충돌하는 순간을 추상적이면서도 캐논에 맞게 보여 준다. NPC들은 전투에 참여하지 않고 각자의 허용 범위 안에서 서로 다른 공명을 제공한다. 도언과 라겐의 직접 대결은 마지막 실루엣 구도로만 암시한다.

이 안은 현재 구현된 수직 데모를 설명하는 영상이 아니라 전체 게임의 비전 콘셉트다. 따라서 공개 시 `full-game vision` 또는 유사한 표기를 붙여 실제 플레이 장면과 구분한다.

## 쇼트 플롯

1. 0.0–3.4초: 도시 전체가 하나의 아래쪽으로 끌려가며 모든 플랫폼과 사람의 실루엣이 같은 방향으로 기운다. 절대 하방의 위압을 표현한다.
2. 3.4–7.2초: 라겐의 거대한 중앙축이 화면 중앙에서 모든 추를 하나로 묶는다. 도언은 반대편에서 무게 전이를 준비한다.
3. 7.2–11.5초: 여러 NPC의 공명 흔적이 각기 다른 방향과 속도로 점등한다. 서로를 통제하지 않고 각자의 플랫폼을 유지한다. 세령의 빛은 따뜻하지만 전투선에는 들어가지 않는다.
4. 11.5–15.0초: 중앙의 단일 축이 사라지고 도시가 여러 아래를 가진 채 안정된다. 도언과 권능을 잃은 라겐이 좁은 전투 공간에 마주 선 실루엣으로 남는다. 마지막은 긴장된 정지 프레임.
