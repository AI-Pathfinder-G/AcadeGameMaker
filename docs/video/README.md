# MiniMax H3 Teaser Direction

## 2026-09-08 재검토

[Astra 영상 점검·플롯 v2](./2026-09-08-astra-trailer-review-and-replot.md)는 현재 사용자 검토용 재설계안이다. 새 요청 범위는 메인 게임·스토리 소개 30~60초 1편과 플레이·시스템 소개 15~30초 2편이며, 제안 길이는 50/24/28초다. 아래 초기 15초 A/B/C 방향과 A+B 합본 계획은 이전 기획 이력으로 보존한다. 기존 생성본은 공개용 최종본으로 채택되지 않았으며 신규 생성은 아직 시작하지 않았다.

## 제작 방향

MiniMax H3용 T2VA 방향 3종을 작성했고, 현재 `Assets/Scenes/`에 A·B·C에 대응하는 MP4 생성본 3개가 있다. 영상은 아직 최종 편집·브랜드 승인·게임 빌드 임포트 대상이 아니며, 참조 이미지가 확보되면 같은 플롯을 I2VA 또는 FL2VA로 전환할 수 있다.

현재 생성본:

- `MiniMax_H3_00003_.mp4` — A 방향 후보
- `MiniMax_H3_00004_.mp4` — B 방향 후보
- `MiniMax_H3_00005_.mp4` — C 방향 후보

공통 출력 기준:

- 15초, 16:9, high-resolution pixel-art 2D cinematic animation
- 640×360 논리 화면과 정수 확대 느낌, 고정된 횡스크롤 프레임
- 냉청회색·먹색 콘크리트, 황동 계량기·배관·거대한 추, 제한적인 청록 전이색과 따뜻한 세령 색상
- 텍스트·로고·대사는 후반 편집에서 삽입. 생성 영상 안에는 읽을 수 있는 문자를 요구하지 않음.
- 카메라는 횡스크롤의 읽기 쉬운 좌우 이동과 제한적인 push-in을 사용하고, 과도한 핸드헬드·실사 질감·3D 카메라 롤은 배제한다.

## 플롯 비교

| 안 | 제목 | 핵심 메시지 | 권장 용도 |
|---|---|---|---|
| A | 무게를 짊어진 자 | 무게 전이와 도시의 구조적 압박 | 첫 공개용, 수직 데모 티저 |
| B | 손대지 않는다 | 인간성 선택은 약함이 아니라 다른 힘의 방식 | 선택·서사 중심 캠페인 |
| C | 각자의 아래 | 8챕터와 진엔딩의 장기 비전 | 정식 공개용, 브랜드 티저 |

권장 순서는 A → B → C다. A는 게임의 조작 정체성을 가장 빠르게 전달하고, B는 차별화된 서사 규칙을 설명하며, C는 아직 구현 범위 밖인 후반부를 최종 비전으로만 보여 준다.

## 캐논·범위 주의

도언·세령·라겐·아인은 현재 가칭이다. 티저에서는 이름을 화면에 직접 표시하지 않는다. 세령은 추적자·동료로 묘사하되 주인공의 선택이나 최종 전투를 대신하지 않는다. NPC들은 진엔딩에서 직접 전투하지 않고 자발적 공명을 제공한다. 인간성 포기 결말에서는 세령이 떠난다는 사실을 감정적 이미지로 표현할 수 있지만, 이를 낭만적 이별로 미화하지 않는다.
