# 운영 전 한정 통합 검토

2026-10-02 실제 `gpt-6-astra` 참여로 수행한 아스트라 계약·통합 검토다. ADR-0037/0038, 문서 권위, 운영모델과 아래 여섯 한정 수용 및 각 루나 원문을 읽고 결과·루나 보고 SHA-256을 현재 파일에서 재계산했다. 코드·키·Unity·Git·원격 실행은 하지 않았다. 기존 테라 `gpt-6-sol` 구현과 루나 `gpt-6-luna` 검증을 아스트라 실행으로 소급하지 않는다.

**판정: 승인된 격리 준비는 계속 진행한다. 새 운영 발급·외부 문서 게시·전체 수용은 아직 허용하지 않는다.** 이번 문서 검토의 새 P0/P1은 0/0이다. 기존 외부 권위 P1과 렌더 내부 경로 P1, 역사적 공백·전이·원격 충돌 및 전체 회귀 관문은 열린 상태다. 한정 수용의 범위를 유지하는 것이며 전체 결함 0 판정이 아니다.

## 현재 진행 허용과 운영 전 관문

1. [승인된 격리 준비](../specs/work-contracts/2026-10-02-q0-cleanclone-signed-preparation.md), SHA `73AA806A7DF6DE29D40FE721471AE2F1AC0F80130B0AE12A4E1D544B16723C3F`의 `REQ-PLAT-061/062`, `AC-PLAT-059/060` 준비 범위만 계속 허용한다. 정확 네 시험·다섯 후속 도구·허용 보조만 격리 경로에서 변경하고, 원문534·LF534·LF505·기존 증거·원래 Git은 불변이다. Git 쓰기는 계약의 `output/q0-cleanclone-signed-prep-r1/selftest-repositories` 내부 실제 합성 저장소에만 한정한다. 테라 결과 뒤 루나 독립 검수와 아스트라 수용이 필요하다. 운영 양성·Unity·전체 회귀는 아직 실행하지 않는다.
2. [외부 권위 발급 초안](../proposals/2026-10-02-q0-external-anchor-issuance-contract-draft.md), SHA `64C2011B4C1D1C348EBCEDDE4A468DC6D5C59E5126880CC7622DD66F4E807E9D`는 계속 초안이다. 후속 운영 계약에 정확 저장소 ID·문서 경로·허용 소스·문맥·스키마·인증 커넥터·신뢰 전달 경계·단명 세션 기한과 실패 폐기·구키/과거 권위 거절을 구체화하고 아스트라가 승인해야 한다. 임의 호출자가 저장소·권위 SHA·신뢰 문맥을 함께 선택하는 경로는 허용하지 않는다. 준비 도구를 운영으로 연결하려면 별도 개정과 최종 소스 재동결·독립 검수가 필요하다.
3. 실제 발급 순서는 승인된 단명 비영속 키 생성 → 공개키 포함 검증 소스 최종 동결 → 별도 허용된 문서 전용 권위 기록 게시·병합 → 인증된 GitHub 읽기로 병합 불변 커밋의 저장소 ID·트리·경로·원시 blob 및 공개키/검증기 SHA 직접 대조 → 현재 권위 고정 → 정확 현재 소스·입력·계획 동결 → 아스트라 원시 계획 SHA/nonce 검토 → 같은 생존 세션에서 한 번 서명이다. 미래 계획·검수 SHA를 선행 소스나 권위 문서에 넣지 않는다. 세션 종료·만료·연결 단절 또는 인증 실패면 폐기하고 운영 거절을 유지한다.
4. 권위 문서의 정확 게시 범위와 원격 충돌은 게시 전에 구체적으로 판정한다. 문서 권위 게시가 QA 도구나 게임 코드 게시를 허용하지 않는다. 기존 사용자 기술 판단 위임 안의 선택은 아스트라가 처리하며 같은 승인을 다시 요청하지 않는다. 이 검토 자체는 원격 쓰기나 새 운영키 발급 계약을 대신하지 않는다.
5. `AC-PLAT-066/067/068` 운영 부분은 실제 외부 권위와 동결 소스·정확 계획·서명, 다른 키/과거 권위/변조/재사용/미병합 기록 거절의 실제 증거 및 루나 독립 검수 뒤에만 수용한다. 그 후에도 `AC-PLAT-059/060`은 실제 깨끗한 복제의 Git·정확 파일/메타/GUID·원문25·현재 의미 변경 계보·전체9선택·188/377행과 새 전체 회귀를 별도 승인 계약으로 검증해야 한다. ADR-0038의 파일별 허용·제외, 내용/직접·간접 의존, 원격 충돌 판단과 아스트라 최종 게시 수용을 생략하지 않는다.

이 문서는 새 현재 증거만 통합한다. 역사428개 공백·14개 미입증 전이, 기존 Renderer GUID7과 외부 권위 P1, 현재 운영 미발급을 종결하지 않으며 원본의 전체 수용·게시 승인 플래그를 변경하지 않는다.
