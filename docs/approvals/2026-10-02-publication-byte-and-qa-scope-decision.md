# 게시 바이트와 QA 검토 범위 결정

2026-10-02 사용자가 두 추천안을 선택했다. 아스트라 역할은 다음과 같이 적용한다.

1. 기존 저장소 줄바꿈 규칙을 유지하고 정규화된 바이트를 새 게시 검토 기준으로 다시 검증한다. 현재 원문 기준 501개와 과거 지문·검수는 보존한다. 새 바이트를 과거 검수 완료 바이트로 취급하지 않는다.
2. 기존 후보의 QA 검사기와 직접 입력 네 개를 함께 검토한다. 추가 네 경로를 포함한 505개는 검토 후보이며 게시 허용 목록이 아니다.

실행 범위는 [Approved 505개 후보 계약](../specs/work-contracts/2026-10-02-publication-lf505-baseline.md)의 `REQ-PLAT-038..040` / `AC-PLAT-036..038`이다. [ADR-0038](../adr/0038-forward-provenance-for-initial-code-publication.md)의 과거 공백 보존·파일별 독립 검수·게시 전 검증은 유지한다. 루나 검수는 기존 사용자 지시대로 한도 회복 뒤 별도 수행한다.
