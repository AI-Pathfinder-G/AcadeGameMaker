# C4 이전 소스 바이트 보존

- 판정: 아스트라의 비실행 증거 보존 승인, 2026-09-29, 실제 `gpt-6-astra`.
- 추적: `REQ-M5D7QC4-001..007`, `AC-M5D7QC4-009/010`.

기본 체크아웃과 인덱스를 바꾸지 않고 C4의 정확 변경 범위를 비교하기 위해 이전 소스 바이트를 별도 보존한다. [구현 승인](2026-09-29-c4-r4-implementation-contract-approval.md)의 동작·서명·실행 허용 범위는 변경하지 않는다. 새 실행이나 구현 수용이 아니다.

보존 범위는 기존 변경 허용 실행 소스7개와 Q0 감사1개, 불변 C1 소스1개다. 저장 위치는 `docs/evidence/c4-runtime-predecessor/<원본파일명>.txt`와 `docs/evidence/c4-runtime-predecessor-manifest.json`이다. 아스트라가 실제 원본 지문을 기존 R11·C1/C2·감사 근거와 대조한 뒤 정확 바이트를 한 번만 복사하고 경로·지문을 원장에 남긴다. `.txt` 사본은 실행·정상 발급기·새 컴파일 입력이 아니다. 기존 파일을 덮어쓰거나 변경된 소스를 이전 소스라고 보존하지 않는다.

원본이 이미 바뀌었으면 이전 지문과 동일한 실제 사본이 있을 때만 보존한다. 확인하지 못한 원본은 부재로 기록하고 원본 존재·원형 동일을 주장하지 않는다. 나중에 감사·도구가 이 사본을 직접 읽으면 정확 고정 입력 목록과 지문에 포함한다. 기본 브랜치·인덱스·기존 실행 및 게시 증거는 보존한다.
