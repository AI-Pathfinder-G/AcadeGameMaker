# C3 실행 모드 실제 발급 시험 위치 승인

아스트라는 솔의 보정 제안 `BAB0264267FA79583C57AD121FC83E28DEE28E2C99DBCA2C7183C9C1868EAF99`와 [루나 후속 폐쇄](../verification/2026-09-29-c3-playmode-fixture-placement-luna-design-review.md) P0/P1=0을 확인하고 Approved C3 끝의 시험 위치 보정을 승인했다. 테라 역할의 별도 `gpt-6-sol` 작업자가 기존 Input.Unity.PlayMode.Tests 조립에 신규 `NewGameConfirmationOwnerPlayModeTests.cs`와 `.meta`만 추가한다.

직접 제공한 임시 경로 환경과 진짜 준비 포트, 실제 입력·생애·발급 경로만 양성 근거로 사용한다. 상위 정상 호출은 정확한 조립 한정 형식·선언 형식·매개변수/반환 서명으로 결속하고 실제 반환 객체 참조를 유지한다. 런타임·조립·friend·실제 저장 경로·다른 시험의 비공개 구성원·정상 권한의 반사 제조는 변경하거나 사용하지 않는다. 새 집중 선택과 기존 536+74개를 분리해 최종 소스에서 실제 실행·독립 검수한다. 아직 구현·시험 수용은 아니다.
