# 새 게임 단일 프로필 초기화 확인 — 사용자 승인

- Date: 2026-09-28
- Status: product direction accepted; implementation contract pending
- Decision owner: user; recorded by Astra

사용자는 기존 진행 데이터가 있는 상태에서 `새 게임`을 선택할 때 확인을 받은 뒤 현재 단일 프로필을 초기화하는 권고안을 승인했다. `계속하기`는 기존 프로필의 거점/새 원정 준비로 이어지고 활성 원정을 복원하지 않는 기존 계약을 유지한다.

## 승인된 의미

- `새 게임` 선택 자체는 저장 데이터를 바꾸지 않는다. 손실을 알리는 명시적 확인 뒤에만 초기화할 수 있다.
- 취소는 기존 진행·설정·입력·튜토리얼·선택 상태와 파일을 변경하지 않는다.
- 확인 뒤 초기화되는 대상은 현재 단일 프로필의 보존 상태다. 원정 중 임시 상태를 저장하거나 복원하지 않는다.
- 저장 성공과 재검증 전에는 새 게임이 시작됐다고 표시하거나 플레이 장면으로 이동하지 않는다.

## 후속 승인 — 이전 진행 보존

`OD-NG-001`은 2026-09-28 사용자 응답 `그래`로 해결됐다. 초기화 전 이전 진행은 별도 수동 복구용으로 보관하며, 새 게임 뒤 자동 복구 후보로 사용하지 않는다. 이것은 보안 삭제 지시가 아니다. 현 `profile.prev.json`은 이전 정상본을 자동 복구할 수 있으므로, 단순히 새 기본 `profile.json`을 저장하는 것만으로는 승인된 동작을 충족하지 못한다. 보관 위치·초기화 도중 종료 시 처리·자동 복구 차단은 별도 명세와 검증을 거쳐야 한다.

이 기록은 기존 `M5D7Q-B`의 synthetic-only 비범위를 변경하거나 파일 초기화·화면 전환 구현을 승인하지 않는다. 별도 `Approved` 명세와 독립 검증이 필요하다.
