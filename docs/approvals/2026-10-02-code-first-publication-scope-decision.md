# 최초 게시의 코드·필수 검증 입력 우선 결정

2026-10-02 사용자가 추가 범위를 아스트라 판단으로 결정하고 적용하도록 위임했다. 아스트라는 코드와 필수 검증 입력을 먼저 선별한다. 후보 밖523개를 일괄 게시하지 않고, 제품 코드·조립 정의·메타·설정 및 선택한 필수 검증의 실제 직접/간접 입력을 정확 경로별로 검토한다. 음원·영상은 실제 제품/필수 검사 의존이 확인되는 파일만 별도 후보로 올리고, 나머지 미디어와 과거 실행 기록은 현 단계에서 보류한다.

이 위임은 게시 조건·독립 검수를 없애지 않는다. 루나 검수는 한도 회복 뒤 별도라는 기존 사용자 지시를 유지한다. [523개 선별 Approved 계약](../specs/work-contracts/2026-10-02-code-first-input-selection.md)의 `REQ-PLAT-048..050`/`AC-PLAT-046..048`에 따라 먼저 원본을 바꾸지 않는 선택 근거 원장을 작성한다. 정확 목록을 아스트라가 대조한 뒤 별도 후보에 적용한다. 과거 증거·정규화505·두 원격 충돌 조사와 기존 Renderer2D P1은 보존한다.
