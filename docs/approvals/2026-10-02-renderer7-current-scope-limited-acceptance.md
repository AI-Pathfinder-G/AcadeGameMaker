# 역사 렌더 참조 현재 정적 원장 한정 수용

2026-10-02 실제 `gpt-6-astra`가 [승인 소유 계약](../specs/work-contracts/2026-10-02-renderer7-current-scope-disposition.md)과 별도 독립 검수 계약에 따라 `REQ-PLAT-077/078`, `AC-PLAT-075/076`의 현재 설치 한정 정적 원장을 수용한다. 새 원장 범위 P0/P1은 0/0이며, 기존 전체 Renderer7 P1은 열린 상태다. 이는 원장 사실의 한정 수용이고 일곱 참조의 비소비·정상성·이식성 수용이 아니다.

현재 파일에서 재계산한 결과 JSON SHA-256은 `97D2784A2E3AF632AB76A6114A4A2C2FA9BAAC21AE88FA249B975548752419E5`, 테라 보고는 `B9C52508B8729D5E054E6BB91896931C289D58EBC966D609A65F3757052F4146`, [루나 독립 보고](../verification/2026-10-02-renderer7-current-scope-luna-review.md)는 `EB23B149E9946F0753B3CF945C6F5DEAFBEBD44E2B8FEB07B2FD74EBAF8C53B1`로 지정 입력과 일치했다. 루나는 실제 C# 1,354개·10검색어·32결과의 집합과 경로/행/원문/SHA, 정적 원문12개 및 보호 지문을 대조했다. 집계 digest는 직렬화 규칙 부재로 독립 재계산하지 않았으며 그 한계를 보존한다.

일곱 역사 GUID 대상은 여전히 미해석이다. APV 여섯 역사 필드는 상속된 Deprecated 선언과 실제 null 관측, falloff 역사 필드는 로드 속성 부재와 직접 C# 검색0건으로 구별한다. 범용 반사 재로드·마이그레이션 가능성을 직접 검색 부재로 배제하지 않는다. 현재 별도 자원·생성 lookup·조건부 패스·셰이더 샘플 경로는 정적 사실이며 특정 격리 실행의 내부 소비 계측이 아니다. 새 APV 자원6개 로드와 v6 점 조명16픽셀 차이는 각각 기존 관측 범위만 유지한다.

테라 `gpt-6-sol`의 원장 작성과 루나 `gpt-6-luna`의 읽기 검수를 아스트라 실행으로 소급하지 않는다. 본 수용에서는 Unity·시험·Git·원격·키·코드 변경을 수행하지 않았다. 다른 플랫폼/플러그인/동적 경로·전체 의존·회귀·깨끗한 복제·게시 관문과 원본의 모든 거짓 승인 플래그는 그대로 유지한다.
