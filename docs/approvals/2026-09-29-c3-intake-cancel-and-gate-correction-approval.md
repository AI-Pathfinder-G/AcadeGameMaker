# C3 진입·취소 필수 증거와 게이트 재인증 보정 승인

아스트라는 Approved C3, 솔 제안 `2026-09-29-c3-intake-and-cancel-required-evidence.md` 지문 `D55936D54119282834909ED4C13C3CA683C981984D9541AAA138290B01BCBE2C` 및 루나 독립 설계 검수 P0/P1=0을 근거로 제한 구현을 승인한다. 추적은 REQ-M5D7QC3-001/003/004/005/006/007과 AC-M5D7QC3-001/003/004/005/006/009/010, 실행 연결 전 AC-007/008 부분 범위다. 이전 r3/r4 동결과 컴파일·검수 이력은 보존한다.

허용 경로는 기존 `Runtime/HubPresentation/Unity/NewGameConfirmationOwnerV1.cs`, 필요할 때 기존 `HubMenuIntentHandoffOwnerV1.cs`의 실제 발급 이력 읽기 보조 한 개, 기존 신규 C3 편집·실행 모드 시험 두 파일 및 증거 문서다. 하위 ABD4/F80, 실행 관리자·라우터, presenter·기존 감사와 필수 회귀 이름은 유지한다. 조립·내부 접근 권한·공개 API·새 토큰·등록부·외부 호출 시험 통로는 추가하지 않는다.

앞선 실제 객체 인증과 상태 무결성을 구분한다. 일곱 진입점 AcceptNewGame/RetryIntake/Confirm/Cancel/OpenFreshDecision/Rearm/CommitForExecution에서 게이트 획득 뒤 동일 실제 객체와 발급 증거를 다시 확인한다. 정상 소비·완료·후속 세대의 이력으로 끝난 오래된 호출은 종료 처리 구간 밖에서 비변경 거절하고 바깥 finally에서 게이트를 해제한다. 아직 미소모인 실제 권한의 슬롯·상태 증거 손상은 종료 처리 구간 안의 무결성 검증으로 전체 폐쇄한다. 진입 자체 실패는 다른 작업의 게이트를 해제하지 않는다. 실제 Busy가 유지한 같은 권한의 정상 재시도는 보존한다.

Q-B 보조가 필요하면 기존 비공개 발급 등록부의 원본 소유자·발급자·presenter·router·record·handle·token·epoch 및 소비 이력을 읽기만 한다. 입력은 명시된 실제 불투명 참조이며 미결 권한을 자동 선택하거나 증거/권한을 반환하지 않는다. 기존 단일 소비와 발급 이력 검증은 유지한다. 소유자 무결성 검증에는 살아 있는 여덟 상태에서 현재 presenter의 router/latch/adapter 결속을 확인한다. ExecutionCommitted/TerminalFailure/Closed에서는 원본 역할·상태·세대·증표 검증을 유지하고 현재 살아 있는 결속 요구만 제외해 기존 종료 상태 조회를 보존한다.

실제 두 임시 실행 묶음의 진입 문맥 불일치, 실제 이전 세대 발급과 새 세대 정상 성공, 정상 구성 API에 의한 발급 후 구조 불일치를 시험한다. 음성 손상 주입은 실제 take 이후 Q-B `_takenRequestProof`, 소유자 `_epochProof`/`_stateProof`, 실행 관리자 `_launchRootWitnessB`의 정확한 단일 항목씩만 허용한다. 등록부 추가·영수증/관찰/권한 정상 제조·여러 필드 동시 위조는 금지한다. 실패 후 원래 증거 값을 복구하더라도 이미 폐쇄된 소유권이 되살아나지 않음을 검증하며, 복구를 새 정상 권한 발급으로 사용하지 않는다.

AC005는 같은 실제 Cancel의 직전·직후에 세 파일, 현재 메모리/reset 필드, 실제 입력 자산·맵·바인딩·활성 상태, 양측 영수증과 이력, 장면 및 시험 실행 묶음의 실행 관찰값을 대조한다. 실제 메모리 대상이 있으면 기존 값과 세대를 복사하고, 없는 대상은 부재 그대로 비교한다. 가짜 전역 메모리나 게임 세션을 만들지 않는다. 실제 자료 비교와 C3 취소가 C1/C2·reset·장면·실행 효과를 호출하지 않는 구조 증거를 합친 합성 범위의 판정이며 실제 게임 세션 전체 보존을 주장하지 않는다. 재무장의 허용된 새 세대 변화는 취소 비교 이후 별도로 검증한다.

지연된 앞선 인증과 게이트 획득 사이의 정확한 경쟁 순서는 실행 재현하지 않았다고 명시한다. 기존 정상 동시·늦은·중복·Busy 시험과 일곱 경계의 정확한 동결 소스 구조 검수로 보장하며 합성 대기 콜백이나 게이트 시험 통로를 만들지 않는다. 실제 Unity 집중·377개 내부 행 출력·필수 562/51/610 회귀와 루나 새 지문 검수 전에는 실행 통과·수용으로 기록하지 않는다. C3 전체 AC-007/008은 미검증이고 C4는 Review다.
