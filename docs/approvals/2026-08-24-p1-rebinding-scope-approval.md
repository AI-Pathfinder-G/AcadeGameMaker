# P1 런타임 입력 재지정 범위 승인 기록

- Date: 2026-08-24
- Status: Approved by user
- Partial decision: `OD-PLAT-001`
- Owner: Sol

## Approved boundary

- keyboard Move composite 네 방향과 모든 Gameplay button action은 재지정 가능
- mouse Attack·Transfer button은 서로 다른 button으로 재지정 가능
- gamepad Gameplay button action은 재지정 가능
- gamepad Move·Aim stick control과 mouse Point axis는 고정
- UI Navigate·Submit·Cancel 및 Pause의 Esc·Start 기본 binding은 제거·대체할 수 없는 안전 경로
- Pause에는 추가 binding만 허용
- stick 축 반전은 binding override가 아닌 별도 설정

## Remaining boundary

같은 control scheme 안의 binding 충돌 처리는 후속 승인으로 확정됐다. override 저장 schema·손상 복구를 확정하기 전에는 `OD-PLAT-001`을 해결 처리하지 않는다.
