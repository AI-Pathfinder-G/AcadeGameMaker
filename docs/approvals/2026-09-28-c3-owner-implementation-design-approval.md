# C3 합성 소유자 구현 설계 승인

날짜: 2026-09-28. 승인: 아스트라. 설계: 솔. 독립 검수: 루나.

승인된 C3 계약 범위에서 `docs/proposals/2026-09-28-c3-owner-implementation-design.md`의 SHA-256 `038E568911410202273CE867D85C594B4929248DE025F326F03444D5DA0ABB30`을 구현 설계로 승인한다. 루나 보정 후 검수는 설계상 중대 결함 0건이며 이전 두 지적을 해소했다.

REQ-M5D7QC3-001..007을 따른다. 기존 요청·의도 이력은 보존하며, 실제 발급 권한과 참조 동일성, 단조 증가 세대, 원자적 확인·취소, 새 커서의 첫 연속 프레임 폐기를 구현한다. 초기 관찰 재시도와 확인 재시도는 서로 다른 권한이다.

C3L 실행 수용 전에는 상위 소유자 통합을 수용하지 않는다. C4는 검토 상태이며 실제 초기화 호출, 실행 보고 발급, 장면·게임 시작 연결은 구현할 수 없다. 미래의 불투명 실행 보고 수신 경계는 실제 보고 발급이나 실행 권한을 만들지 않는다.

이 문서는 설계 승인이다. AC-M5D7QC3-001..010 및 AC-M5D7QC3L-005 실행 통과를 뜻하지 않는다. 구현은 테라, 독립 검증은 루나, 최종 통합은 아스트라가 수행한다.
