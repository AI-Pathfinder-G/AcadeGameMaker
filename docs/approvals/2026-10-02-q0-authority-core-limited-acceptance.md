# Q0 분리 서명 검증 핵심 제한 수용

통합 책임자는 2026-10-02 테라 결과 SHA `EBE9061C0A0152D06A132A90D7CA064B6F7810ECC4C9FBBF017EC2DA83EC6FFB`와 별도 루나 보고 SHA `54C8F6B40D8DCC7203C5EA46B021ECB5D49859EB90CA7B13AE2D6332468E0447`을 읽고 `AC-PLAT-068`의 핵심 형식·변조 거절·운영 우회 부재를 제한 수용한다. 격리 정상/음성15개와 추가 불량 UTF8 거절은 실제 실행 증거다. 최종 세 소스 SHA는 구현 보고의 지문과 같다.

운영 진입점은 현재 공개키·외부 인증 루트가 없어 항상 종료2로 거절한다. 이는 준비 상태의 안전한 거절이며 실사용 계획 승인 기능의 완성을 뜻하지 않는다. 합성 시험의 키는 단명 메모리 객체로 폐기했고 실제 운영 키를 생성하지 않았다. `AC-PLAT-066/067`의 외부 승인 루트·실제 키/소스 동결·분리 서명과 기존 Q0 실행 연결은 열린 상태다. 전체 의존/복제/회귀/코드 게시를 수용하지 않는다.

루나 보고 마지막 줄의 포괄적인 QA 미실행 문구는 같은 보고의 실제 격리 자기시험 실행과 맞지 않는다. 실제 수행은 격리된 서명 핵심 QA이고 기존 제품/Unity/전체 회귀 실행은 없었다. 이 수용은 실행 기록을 기준으로 그 구별을 명시하며 원본 보고와 지문은 보존한다.
