# Sol이 전체를 오케스트레이션하고 Terra가 단위 파트를 설계·구현한다

GPT-5.6 Sol은 멀티에이전트 핵심 설계, 역할 배분, 시스템 간 계약, 충돌 해결, 챕터·인물·엔딩의 서사 캐논, 최종 통합과 승인에 전념한다. GPT-5.6 Terra는 Sol이 확정한 계약과 캐논 경계 안에서 개별 게임플레이 시스템, Unity 기능, 배정된 챕터·콘텐츠 단위를 설계·구현한다. Luna는 테스트와 독립 검수를 맡고 Ollama는 비핵심 초안과 반복 작업만 수행한다. 이 분리는 전체 맥락과 품질 기준을 Sol에 집중하면서 Terra의 비용 효율을 단위 개발 처리량으로 활용한다.
