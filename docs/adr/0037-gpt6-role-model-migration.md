# ADR-0037: 솔·테라·루나 역할의 GPT-6 전환

- 상태: accepted — 사용자 명시 지시를 아스트라가 적용
- 날짜: 2026-09-29
- 대체 범위: ADR-0032의 활성 모델 버전 지정만 대체한다. 역할·문서 권위·구현 승인·독립 검수 요건은 유지한다.

사용자는 모든 솔·테라·루나 모델을 5.6에서 6으로 변경하고, 이후 5.6 호출을 금지하며 중단 작업을 변경된 모델로 재시도하도록 지시했다. 기존 5.6 구현·설계 담당에서 사용량 오류가 발생했으므로 같은 작업자를 재개하지 않고 명시 모델로 새 작업자를 생성한다.

| 역할 | 실제 호출 모델 | 소유권 |
|---|---|---|
| 아스트라 | `gpt-6-astra` | 계약 승인·배분·최종 통합 |
| 솔 | `gpt-6-sol` | 제한된 설계·반대 검토 |
| 테라 | 별도 `gpt-6-sol` 작업자 | 구현·구현 시험 |
| 루나 | `gpt-6-luna` | 독립 검수·회귀 증거 |

현재 서브에이전트 도구는 `gpt-6-sol`과 `gpt-6-luna`를 제공하지만 `gpt-6-terra`를 제공하지 않는다. 테라는 구현 역할 이름으로 유지하고 실제 호출 모델을 `gpt-6-sol`로 명확히 기록한다. 존재하지 않는 식별자를 만들거나 실제 테라 모델을 호출했다고 주장하지 않는다. 솔과 테라는 별개 작업자이며 구현자는 자기 구현을 독립 수용할 수 없다.

향후 새 작업·재시도·대체 경로에서 5.6 모델을 호출하지 않는다. 과거 ADR·검수·참여 원장의 실제 5.6 참여 이력은 사실로 보존한다. 새 참여 기록은 실제 GPT-6 모델과 역할·정확한 증거를 기록한다. 사용자 지시는 변경된 모델로 한 차례 재시도할 근거이며 할당량 해소를 보장하지 않는다. 재시도에서도 한도·인증·모델 오류가 발생하면 반복 호출을 멈추고 실제 오류를 보고한다. 별도 유료 API 경로나 제품 동작 변경은 승인하지 않는다.
