# 수직 데모 P0를 공동장부 원정 계약으로 통합한다

- Status: accepted
- Date: 2026-08-24
- Approved by: User, integrated by GPT-5.6 Sol

## Context

15분 수직 데모를 구현하려면 무게 전이, 방 조립, 실패와 보존, 인간성 선택, 분기 기술, 적과 중간보스가 서로 같은 생명주기와 검증 경계를 사용해야 한다. 각 항목을 따로 정하면 선택 직후 전이 대상이 사라지거나, 저장 시점이 충돌하거나, 무게 전이가 보스전에 실질적인 이점을 주지 못하는 통합 실패가 발생할 수 있다.

## Decision

- 무게 전이는 한 번에 한 대상, 6.0 유닛, 결정적 각도·거리·안정 ID 순위, 21틱 전환 잠금을 사용한다.
- 수작업 방은 정확히 6개이며 한 런은 `R01`, 두 변주방, `R06`의 네 방을 사용한다. 지원 시드 101/202/303/404는 저작된 불변 snapshot이다.
- 실패는 체력 0, 낙하 한계선, `Lethal` 압착이며 활성 런은 저장하지 않는다. 설정·튜토리얼·확정 선택·기술·완료 분기만 승인된 경계에서 보존한다.
- 선택 대상은 공동장부 보관자 유담이다. 거부를 무시하면 수탈 기술 `압착 판결`, 범위가 있는 동의를 보존하면 연대 기술 `공동 기준면`을 얻는다.
- 일반 적은 인간 집행자 `징수보행관`과 `부유측량사`, 중간보스는 scripted 압류추를 쓰는 인간 환수관 오르단이다.
- 선택 직후 비치명 봉쇄선에서 선택 기술을 검증하고, 성공 경로 마지막에 히로인이 독립된 추적자로 처음 등장한다.
- 공개 사건, 틱 순서, 피해 중복 제거, 성공 종료와 원자 저장 순서는 SYSTEM-CONTRACTS가 소유한다.

세부 규범 수치와 인수 기준은 VD-02~VD-07 및 SYSTEM-CONTRACTS에 둔다. 이 ADR은 P1 이동 기본값, 저장 JSON 필드, 픽셀 밀도·팔레트, 전체 장면 연출을 결정하지 않는다.

## Consequences

- 여섯 P0 결정은 하나의 승인 경계로 닫힌다.
- 두 선택 모두 진행 가능하며 기술의 강점과 주체성 결과가 관찰 가능하다.
- 네 시드와 보스 패턴은 런타임 RNG 없이 재현할 수 있다.
- 관련 스펙은 Review로 전환할 수 있지만 P1과 교차 계약이 남아 있어 즉시 구현하지 않는다.
- Unity 프로젝트 생성과 에셋 임포트는 관련 스펙이 Approved가 되기 전까지 금지된다.

## Alternatives rejected

- 방과 소켓을 런타임 RNG로 생성: 작은 데모의 결정성과 검수 비용을 악화시킨다.
- 유담 또는 동의 앵커를 무게 전이 대상으로 추가: 상자·적이라는 핵심 대상 계약을 불필요하게 확장한다.
- 연대 기술을 동적 양끝 추적 발판으로 구현: Unity 2D 물리 끼임과 비결정적 collider 갱신 위험이 크다.
- 보스 압류추를 Dynamic joint로 구현: 전이·회수 중 보스 물리와 패턴 상태가 불안정해진다.
