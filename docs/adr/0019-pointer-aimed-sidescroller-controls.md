# 포인터 조준형 횡스크롤 조작을 사용한다

- Status: accepted
- Date: 2026-08-24
- Decision owner: Sol
- Approved by: user

횡스크롤 이동과 중력 대상 조작을 동시에 수행해야 하므로 왼손은 키보드 이동·플랫폼 조작, 오른손은 마우스 조준·전투를 맡는다. 키보드 `J-K-L` 전투와 마우스 조준을 혼합하거나 바라보는 방향만으로 자동 타겟을 고르는 대신, 마우스로 공간의 적·상자·보스 payload를 직접 가리키는 `포인터 조준형 횡스크롤 액션`을 사용한다.

키보드·마우스 기본 역할은 WASD 이동, Space 점프, Shift 대시, E 상호작용, Q 선택 기술, 좌클릭 기본 공격, 우클릭 무게 전이·회수다. 게임패드는 왼쪽 스틱 이동, 오른쪽 스틱 조준, RT 공격, LT 전이, RB 선택 기술, A 점프, B 대시, X 상호작용으로 같은 의미 명령을 제공한다.

이 결정은 [ADR-0018](./0018-vertical-demo-p0-integration.md)의 단일 대상·6유닛·LOS·결정성 요구를 유지하지만, 바라보는 방향과 50도 원뿔을 전제로 한 후보 정렬은 포인터·스틱 조준 계약으로 교체한다. 정확한 보정 반경, 후보 정렬, 게임패드 조준 유지 시간은 `OD-PLAT-001`의 다음 결정에서 고정한다.

## Consequences

- 기본 공격과 무게 전이는 같은 공간 조준 문법을 사용한다.
- 마우스는 게임플레이 조준·전투와 UI에 사용하며 클릭 이동은 사용하지 않는다.
- 게임패드는 오른쪽 스틱 조준과 trigger/bumper 전투를 사용하고 face button 조작 중 조준 유지 보조가 필요하다.
- 수직 방과 전투는 전방 50도 원뿔에 대상을 맞출 필요가 없지만 커서·카메라 변환과 게임패드 보정의 결정적 검증 비용을 부담한다.
