# 연애 필수 진엔딩·불가피한 희생·7장 재도전

- Status: accepted direction / 2026-09-09 사용자 승인. Astra 기록. 세부 구현 스펙 승인이 아님.

1. 진엔딩은 도언의 일관된 인간성 보존, 세 핵심 약속, 기존 깊은 유대 기준(75 이상), 세령과의 상호 연애 성립·유지, NPC들의 자발적 공명을 모두 요구한다. 신뢰와 자신의 대가를 감당하는 선택이 관계와 자격을 누적시킨다. 선물/반복 대화로 핵심 신뢰 손상이나 약속 위반을 상쇄하지 않는다.
2. 기존 관계 균열 회복은 일상 의견 차이와 핵심 신뢰 손상을 구분해 재정리한다. 실제 구현 이벤트/수치는 후속 Review 계약에서 확정한다. 핵심 약속의 영구 파기 및 수탈 비가역 규칙은 유지한다. 비연애 진엔딩 허용 제안은 폐기한다.
3. 어느 서사 루트에서도 살릴 수 없고 자신의 소망을 이루지 못하는 상징적 희생자 최소 한 명을 둔다. 인물의 이름/사연/사망 시점은 Astra가 구성한다. 플레이어의 전투 실패나 선행 선택을 사망 원인으로 강제하지 않는다.
4. 7장 중간 선택은 확인 후 저장하며 후반전 실패는 동일 선택의 후반전 시작에서 재도전한다. 보상/인간성/주민 상태의 중복·역행 방지, 중단 중 저장 실패 처리는 별도 계약으로 고정한다.
5. 최신 8챕터 재정렬을 방향으로 수용한다. 서하 CH4, 풍낭모체 CH6, 무진 CH7 공통 전반전→선택→분기 후반전. 서로 다른 8개체, 라겐만 반복. 옛 CH6 서하/무진 숭배 거절 동기는 이력으로 남긴다.
