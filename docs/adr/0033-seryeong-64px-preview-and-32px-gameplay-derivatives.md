# ADR-0033: 세령 64px 미리보기와 32px 인게임 파생본

- Status: accepted
- Date: 2026-09-20
- Decision owner: user direction, integrated by Astra

## Context

프로젝트의 승인된 렌더 기준은 640×360 내부 게임플레이 캔버스, 18 PPU 환경·월드 밀도, 고정 월드 프레이밍과 지원 출력으로의 정수 확대다. 세령의 새 제작 마스터는 128×128 셀 안의 64px 전신을 사용한다. 이를 640×360에서 캐릭터만 36 PPU로 배치하면 월드 크기는 유지되지만 소스 2픽셀이 논리 1픽셀로 축소되어 제작 목적이었던 의상·헤어 세부가 사라진다. 반대로 내부 렌더를 1280×720으로 바꾸면 카메라, 조준 역변환, UI, 최소 640×360 지원과 정수 배율 계약 전체를 다시 검증해야 한다.

## Decision

현재 수직 데모는 640×360·18 PPU·기존 월드 프레이밍을 유지한다.

- 64px 자료는 의상 제작 마스터와 옷장 우측 고해상도 미리보기로 보존한다.
- 실제 게임플레이는 같은 의상·헤어·팔레트를 표현하는 수작업 검수된 32px 양방향 아틀라스를 사용한다.
- 하나의 수용된 의상은 `64px 미리보기 + 32px 양방향 인게임 아틀라스 + canonical clip map`을 원자적인 외형 미디어 패키지로 가진다.
- 32px 자료는 최근접 축소 후보에서 시작할 수 있으나 자동 축소 결과만으로 Accepted가 되지 않는다. 얼굴, 헤어, 의상 식별점, 실루엣, 손·활 접점, 발 기준선과 프레임 연결을 수동 보정·검수해야 한다.
- 미리보기와 인게임 파생본이 다른 의상·헤어·팔레트·비율로 읽히면 패키지 전체를 거부한다.
- 현재 `source_only` 자료와 0/432 Accepted 상태는 이 결정만으로 승격되지 않는다.

## Consequences

- 기존 카메라·조준·UI·충돌·월드 프레이밍·최소 해상도 계약은 유지된다.
- 첫 실제 미디어 수용 계약은 정확한 한 의상과 필요한 동작·양방향·해시·권리 증적을 지정한다.
- 64px 세부를 인게임에서도 그대로 보여주는 1280×720 내부 렌더 전환은 향후 별도 ADR·플랫폼 계약·회귀 프로그램이 필요한 독립 마이그레이션이다.
- 캐릭터만 36 PPU로 섞는 방식은 채택하지 않는다.
