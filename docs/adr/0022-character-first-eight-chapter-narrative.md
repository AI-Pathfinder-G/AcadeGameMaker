# 전체 서사를 인물 중심 8챕터와 자기정당화형 광오로 구성한다

- Status: accepted
- Date: 2026-08-24
- Decision owner: Sol
- Approved by: user

## Context

초기 `죽은 자의 갱신` 계열 안은 만료·서명·계약 제도가 인물보다 앞서 각 챕터가 사례집처럼 분리됐고, 주인공과 히로인의 관계 발전과 나쁜 선택의 인격적 대가가 부족했다. 사용자는 인물 구축부터 다시 시작해 기승전결을 강화하고, 히로인과의 관계 발전, 주인공의 도덕적 갈등, 나쁜 선택이 누적될수록 악에 물들고 광오해지는 모습을 요구했다.

## Decision

- 전체 서사는 8챕터를 `기 1~2장 → 승 3~4장 → 전 5~7장 → 결 8장`으로 구성한다.
- 중심 관계는 최초 공명 설계자 `도언`, 독립 추적자 `세령`, 최초 구조 생존자이자 현장 조정자였던 `라겐`, 세령의 언니이자 설계 열쇠 보유자인 `아인`의 네 사람이다. 이 이름들은 역할과 관계를 지칭하는 현재 가칭이며 OD-NAR-005 해결 전에는 최종 이름으로 고정하지 않는다.
- 라겐은 공동설계자가 아니며, 도언을 제거하려는 단순 효율 관료가 아니라 함께 통치하기를 원하는 개인적 대항자다.
- 아인은 구출 대상이면서 자기 구출과 각인 사용을 거부하거나 제한할 권리를 가진다.
- 세령과 도언의 관계는 경계·거래·신뢰·애정·균열·사랑과 거부·선택된 동행 또는 이별로 발전한다. 세령은 도언의 인간성을 대신 선택하지 않는다.
- 나쁜 선택의 누적은 외부 조종이 아니라 도언 자신의 자기정당화인 `광오`다. 자기희생은 독점적 책임, 감사 요구, 타인의 도구화, 선택권 제거로 상승한다.
- 수탈과 연대는 모두 진행 가능한 기술군을 유지한다. 수탈은 더 직접적이고 효율적이지만 관계·NPC 공명·결말에 실질적인 대가를 남긴다.
- 진엔딩은 인간성 보존, 핵심 약속, 충분한 유대, NPC들의 자발적 공명을 모두 요구한다. NPC와 세령은 진보스전에 직접 참가하지 않는다.

## Rejected alternatives

- 만료·위조 서명을 중심으로 각 장에서 새로운 피해 사례를 해결하는 옴니버스 구조.
- 주인공이 착취 체계를 처음 설계했거나 진보스가 공동설계자라는 설정.
- 히로인이 도덕적 정답을 알려주거나 사랑으로 주인공을 자동 정화하는 구조.
- 악령·각인·기억이 주인공을 조종해 타락 책임을 면하게 하는 구조.
- 나쁜 선택이 외형과 기술만 바꾸고 관계와 결말에는 영향을 주지 않는 구조.

## Consequences

- 챕터별 사건은 독립 사례가 아니라 중심 네 인물의 관계와 다음 장 상태를 바꿔야 한다.
- 타락 표현은 말투, 호칭, 자세, 전투 후 행동, 타인에 대한 인식과 세령의 경계 변화에 함께 나타나야 한다.
- exact 유대 수치, 광오 단계의 발동 조건, 분기별 생존자와 대사, 챕터 보스 세부 구성은 후속 스펙에서 결정한다.
- 수직 데모의 유담·오르단·히로인 첫 등장 계약은 변경하지 않는다.
