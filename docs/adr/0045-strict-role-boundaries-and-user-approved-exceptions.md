# ADR-0045 — 역할 제한과 사용자 사전 승인에 의한 예외

- 상태: Accepted — 2026-10-24 사용자 직접 지시.
- 범위: 현재·향후 프로젝트 작업의 모델 역할과 예외 권한. ADR-0043의 역할 범위를 아래와 같이 좁히며 모델 기준과 역사 증거는 유지한다.

## 배경

사용률 감사에서 Astra가 상세 소스·실패 원시 판독과 작은 실행 조건의 반복 승인까지 관여한 것이 확인됐다. 사용자는 Astra의 사용을 통합 승인 및 프로젝트 전체 레벨의 기획설계 변경이 필요한 경우로 한정하고 직접 구현을 금지했다. 개별 파트 설계·구현은 6.1 Sol, Luna는 기존 직무 유지로 명시했으며 불가피한 예외도 사유 제출과 사용자 사전 승인을 요구했다.

## 결정

정확한 최상위 작업지침은 저장소 루트 AGENTS.md의 「최상위 사용자 지시 — 2026-10-24 역할 제한·예외 사전 승인」이며 docs/agent-operating-model.md에도 반영한다.

Astra는 통합 승인·최종 통합 판정과 프로젝트 전체 기획설계 변경 결정만 맡는다. 그 결정에 필요한 계약·인터페이스·범위 승인 기록은 허용하지만 상세 파트 설계·일상 진단·직접 구현·시험/빌드 실행 담당으로 사용하지 않는다. 통합 코드나 충돌 해결 코드의 실제 수정도 Sol 담당이다.

Sol gpt-6.1-sol이 개별 파트 설계·조사·계약 초안·구현·구현 검사·시험 및 실행 도구를 담당한다. Luna gpt-6-luna는 사전·사후 반례, 독립 코드·서사 검토, 회귀·빌드 검증과 증거 요약의 기존 역할을 유지한다. Astra 판정에 필요한 자료는 Sol/Luna가 모아 차이와 결정 사항 중심으로 제출하며 허용 범위 안 작은 보정마다 승인을 다시 요청하지 않는다.

예외 작업은 수행 전 사유·정상 역할로 처리 불가한 이유·대안·모델·범위·위험·기간/예산을 사용자에게 제출하고 명시적 사전 승인을 받은 경우에만 수행한다. Astra/Root 자체 승인이나 기존 자율 개발 위임은 이를 대신하지 않는다. 미응답은 승인이 아니다. 승인은 해당 예외에만 적용하고 예외 대기 중에는 충돌 없는 기승인 작업을 계속한다. Root라는 역할명이 실제 모델 제한을 우회하지 않는다.

ADR-0044의 사용자 중간 조작 면제는 정상 역할 안에서 계속 적용하되 역할 예외의 사전 승인 의무에는 적용하지 않는다. 기존 승인 제품 범위·필수 AC·동결 문서·소스·실패·소진·실제 참여 이력은 바꾸지 않는다. ADR-0041의 실제 가용 상위 버전 확인은 역할을 확대하지 않는다. 이번 문서 반영은 사용자가 직접 지시한 규칙 변경이며 역할 예외나 제품 구현 승인이 아니다.

## 적용 확인

AGENTS.md 최상단, 운영 모델, 문서 지도와 ADR 색인에서 새 권위 및 사용자 사전 승인 조건을 대조한다. 제품 소스·시험·빌드는 이번 변경 범위가 아니다.

## 2026-10-24 후속 사용자 정정 — 루나 기준 6.1

- **루나 기준 버전 정정 — 2026-10-24 사용자 직접 지시**: Luna의 현재 기준은 `gpt-6.1-luna`다. 신규·재시도·대체 배정은 이 기준 이상에서 실제 제공되는 동일 계열 안정 버전만 사용한다. 호출 목록에 없으면 미제공으로 기록하고 해당 배정을 보류하며 `gpt-6-luna`로 임의 하향 대체하지 않는다. 예외는 사유 제출 후 사용자 명시적 사전 승인에 한한다. 과거 실제 `gpt-6-luna` 실행·검수 기록은 변경하지 않는다.

위 결정 본문의 gpt-6-luna는 최초 작성 시점의 기준이며 현재·향후 배정에는 이 후속 정정의 gpt-6.1-luna가 우선한다. 실제 호출 지원 여부와 기준 버전은 구분한다. 아직 제공되지 않은 모델을 호출하거나 실행했다고 표시하지 않는다.

## 2026-10-24 최종 사용자 정정 — 루나 기준 6 원복

- **루나 기준 버전 원복 — 2026-10-24 최신 사용자 지시**: Luna의 현재 기준은 `gpt-6-luna`다. 앞선 6.1 기준 지정과 그 미제공에 따른 배정 보류를 대체하며 신규·재시도·대체 작업에 실제 제공되는 `gpt-6-luna`를 사용할 수 있다. 향후 실제 제공되는 같은 계열 상위 안정 버전은 ADR-0041에 따라 적용한다. 기존 직무·역할 예외의 사용자 사전 승인 조건과 과거 실제 모델 기록은 유지한다.

직전의 「후속 사용자 정정 — 루나 기준 6.1」은 당시 지시 이력으로 보존하며 현재 배정에는 이 최종 정정이 우선한다. 사용자의 직접 원복 지시이므로 gpt-6-luna 배정에 별도 하향 예외 승인을 요구하지 않는다. Astra와 Sol 기준 및 역할 제한은 변경하지 않는다.
