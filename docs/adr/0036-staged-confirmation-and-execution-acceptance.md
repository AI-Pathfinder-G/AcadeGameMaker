# 확인 소유자와 실제 실행 연결의 단계적 수용

- 상태: accepted — 아스트라가 단계적 수용 순서만 승인했다. C4 구현 승인은 아니다.
- 날짜: 2026-09-29

Approved C3는 실제 실행 결과의 출처까지 검증하도록 요구하지만 실제 발급기는 Review C4의 범위이며, C4는 C3 독립 검증을 선행 조건으로 두므로 전체 수용 순서에 순환이 있다. 실제 출처 요구를 유지하면서 C3의 관찰·결정·취소·새 입력 세대·실행 직전 권한 폐쇄를 먼저 독립 검증하고, 실행 결과에 의존하는 나머지는 별도로 승인된 C4와 공동 최종 검증한다. 선행 단계 수용을 C3 전체 Verified로 기록하지 않는다.

검증용 결과 발급기나 반사 호출로 정상 권한을 제조하는 대안은 실제 C1 결과의 출처를 증명하지 못하므로 배제한다. C3의 선행 단계에도 AC-M5D7QC3-010의 집중·필수 회귀와 루나 P0/P1=0, 아스트라 수용을 적용하며, 실제 소유자·재무장 변경 이후에는 필요한 실행 모드 회귀를 새 소스로 수행한다. C3L 관찰 단위의 제한된 편집 모드 검증으로 이를 대신하지 않는다.

선행 단계의 AC-M5D7QC3-007/008은 실행 연결 전 부분 증거일 뿐이며 전체 기준은 Open/Not Verified로 유지한다. 공동 최종 단계에서 해당 잔여 증거와 AC-M5D7QC4-001..010 전체를 검증한다. 실제 결과 발급에 의존하는 기준을 선행 단계에서 통과로 처리하지 않는다.

결정 근거는 [순환 해소 제안](../proposals/2026-09-29-c3-c4-acceptance-cycle-resolution.md)이다. C4는 별도 계약 승인 전까지 Review를 유지하며, 이 결정은 제품 동작·수용 기준·현재 코드 허용 목록을 완화하지 않는다.

아스트라는 루나의 [보정 후 독립 검수](../verification/2026-09-29-vd09-m5d7q-c3-c4-acceptance-cycle-resolution-luna-closure.md) P0=0/P1=0을 확인하고 2026-09-29에 승인했다. 검수 당시 제안서 SHA-256은 `A8D35076BADAD0E897C9E27F15055956A3B13D96AE222BE81953129ECB4660B3`이며, ADR 초안 지문과 승인 후 상태 변경을 구분한다. 실제 실행·통합 수용은 아직 수행하지 않았다.
