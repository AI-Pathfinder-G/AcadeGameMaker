# Sol 오케스트레이션 아래 Terra와 Kimi가 구현하고 Luna가 독립 검수한다

- Date: 2026-08-25
- Decision owner: Sol
- Approved by: user

Sol은 전체 진척, 시스템 간 계약, 중요 결정, 충돌 해결과 최종 통합을 소유한다. Terra는 코어 프로그램과 단위 설계·구현의 책임자로서 Kimi가 제출한 구현 초안과 패치를 검토·교정·통합한다. Kimi K3는 Sol이 승인한 작업 계약과 Terra가 정한 단위 경계 안에서 Unity C# 초안, 반복 구현, 테스트 초안과 격리된 패치 제안을 적극 수행할 수 있지만 공개 계약·아키텍처·캐논·승인·통합은 결정하지 않는다.

Luna는 게임 구현을 독립 검수하고 AC ID에 따른 수정 피드백을 제공한다. GLM 5.2는 QA 시나리오와 검증 프로세스를 보완하되 결정권을 갖지 않는다. 게임 기능이 완성 단계에 도달하면 MiniMax M3가 Sol이 승인한 QA 프로그램 계약에 따라 구현안을 제출하고, Terra가 기술적으로 통합한 뒤 Luna가 QA 프로그램 자체를 독립 검수한다.

중요 지시사항과 계약 변경 요청은 Terra가 Sol에 보고한다. Kimi·GLM·MiniMax의 출력은 비권위 제안이며 Terra 또는 Luna의 검토와 Sol의 최종 수용 없이는 프로젝트 계약이나 통합 결과가 되지 않는다. Cloud 모델에는 비밀, 자격 증명, 개인 정보 또는 작업에 불필요한 로컬 자료를 제공하지 않는다.

## Consequences

- 구현 처리량을 높이되 Terra가 단위 구현의 책임과 품질 소유권을 유지한다.
- Kimi가 코어 코드를 제안할 수 있지만 Sol 계약을 변경하거나 직접 통합하지 못한다.
- Luna는 기능 구현과 QA 도구 모두를 독립 검수한다.
- QA 프로그램 구현은 게임 기능 완성 단계와 별도 Approved 계약을 게이트로 삼는다.
- Sol은 매 마일스톤의 시작·중단·재작업·통합을 결정한다.
