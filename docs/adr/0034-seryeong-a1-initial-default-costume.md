# ADR-0034: 세령의 초기 기본 의상은 A1

- Status: accepted
- Date: 2026-09-21
- Decision owner: user direction, integrated by Astra

## Context

현재 런타임 의상 카탈로그에는 수용된 기본 의상이 없으며, 첫 세령 미디어 계약은 A1 의상과 H1 머리 모양에 대해 가장 강하게 고정된 원본·보정·검증 경로를 갖고 있다. `story` 의상을 먼저 기본값으로 제작하는 선택도 가능하지만, 이는 별도 원본 제작과 동일한 미디어 수용 절차를 선행해야 한다.

## Decision

- 세령의 수직 데모 초기 기본 의상은 `seryeong.costume.a1.v1`로 한다.
- 머리 모양은 첫 패키지 범위에서 H1 정체성을 유지한다.
- A1은 미디어 패키지 수용과 이후 Unity 임포트·게시 계약을 모두 통과한 뒤에만 `Accepted` 및 유일한 `defaultGrant=true` 런타임 행이 될 수 있다.
- `story` 의상은 향후 서사·옷장 의상으로 남기며, 이 결정만으로 삭제·수용·기본 지급되지 않는다.
- 이 ADR은 A1 미디어 자체를 수용하거나 Unity 자산·카탈로그를 즉시 변경하지 않는다.

## Rationale

A1/H1은 현재 정확한 원본 해시, 64px 제작 기준, 32px 게임플레이 파생 규칙과 첫 미디어 검증기가 이미 연결되어 있어 가장 짧고 신뢰 가능한 기본 의상 경로다. 기본값을 명시함으로써 첫 게시 시 `NoAcceptedDefault`를 해소하되, 미완성 미디어가 착용 가능해지는 우회는 허용하지 않는다.

## Consequences

- 첫 미디어 계약의 기본 의상 선택 게이트는 해결된다.
- 권리·미디어·임포트·회귀 검증 게이트는 그대로 유지된다.
- 이후 카탈로그 게시 계약은 수용된 기본 의상을 정확히 하나만 허용하고, 실패 시 기존 완전 바인딩과 카탈로그 상태를 보존해야 한다.
