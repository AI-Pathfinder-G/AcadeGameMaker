# ADR-0040: 솔·테라의 6.1 솔 통일과 루나 6 고정

- 상태: accepted — 2026-10-03 사용자 명시 지시.
- 범위: 이후 모델 배정·재시도·대체 호출. 제품 구현, 운영 실행, 원격 게시의 승인 범위는 변경하지 않는다.

사용자는 기존 솔·테라 역할의 모델을 `gpt-6.1-sol`로 통일하고 표준 문서를 수정하여 다음 작업부터 즉시 적용하도록 지시했다. 이어 루나도 5.6이 아닌 `gpt-6-luna`로 사용하도록 확인했다.

| 역할 | 현재 호출 모델 | 소유 |
|---|---|---|
| 아스트라 | `gpt-6-astra` | 총괄·범위·계약 승인·최종 통합 |
| 솔 | `gpt-6.1-sol` | 한정 복잡 설계·반대 검토 |
| 테라 | 별도 `gpt-6.1-sol` 작업자 | 구현·구현 검사·도구·영향 조사 |
| 루나 | `gpt-6-luna` | 독립 사전·사후 검수·회귀·빌드 검증 |

모델이 같아도 솔·테라의 역할과 과업을 구분하고 구현자가 자신의 작업을 독립 수용하지 않는다. 이후 솔·테라 신규 작업·재시도·대체 호출에 기존 `gpt-6-sol` 작업자를 재개하지 않는다. GPT-5.6과 기존 금지된 외부 모델 호출 금지는 유지한다. 호출 도구에 없는 모델 식별자를 만들거나 지원하지 않는 실행 방식을 주장하지 않는다.

진행 중이던 `gpt-6-sol` 영향 조사는 중단하고, 보존된 보고와 실제 조사 범위를 새 `gpt-6.1-sol` 작업자에게 인계한다. 기존 루나는 이미 `gpt-6-luna`이며 그 배정을 유지한다. ADR-0037의 당시 결정, 기존 승인·실행 증거 및 참여 원장의 실제 모델은 덮어쓰지 않는다. 이 변경은 게임 구현률을 올리거나 Q0 R4 인간 운영 승인을 대신하지 않는다.
