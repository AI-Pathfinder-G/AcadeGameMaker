# ADR-0042 — 1챕터 전체 체험을 최우선 전달물로 전환

- 상태: Accepted — 2026-10-03 사용자 직접 우선순위 지시. 제품 구현 범위 승인은 별도다.
- 결정: 실제 아스트라 `gpt-6-astra`.

사용자는 자신이 1챕터를 체험 플레이할 수 있는 수준을 최우선 목표로 지정했다. 이에 ADR-0039의 실제 플레이 우선 원칙을 유지하면서, 단일 전투 체험→데모→1챕터의 직렬 납품 순서를 대체한다. 최초 단일 전투는 CH1의 입력·표시·수명주기 연결 단계이며 최종 납품 목표가 아니다.

최종 대상은 캐논의 CH1 `거부하는 사람`이다. VD-00은 전체 챕터를 범위 밖으로 두고, 전체 서사 NAR-00은 Review이므로 데모를 CH1으로 이름만 바꾸거나 전체 8챕터를 승인하지 않는다. CH1 한정 제품 계약에서 기존 VD-06 성공 순서와 CH1 도입·유담의 결과·세령의 독립 추적자 등장·아인 단서·다음 장 인계 경계를 별도로 명시한다. 1~2장의 조건부 협력 아크 전체를 CH1에 당겨 넣지 않는다.

작업 순서는 CH1 범위/의존 확정과 첫 연결 묶음 승인, 생산 입력·전투·표시·재시도 연결, 거점/방/선택/기술/서사 연속 연결, 현재 소스 빌드와 독립 양분기 완주다. 각 단계의 좁은 Approved 구현은 전체 CH1 계약의 미결 사항과 분리해 진행할 수 있다. 미래 단계의 독립 완주를 첫 구현의 전제에 넣지 않는다.

기존 데모 수량과 AC, 필수 회귀, Q0 인간 승인·동결 원문·원격 권한은 유지한다. 게시 완료를 로컬 개발의 자동 선행으로 삼지 않는다. 실제 의존만 기록한다. 절차 변경으로 제품 진척을 올리지 않으며 일일 감사는 별도 소유자가 담당한다.
