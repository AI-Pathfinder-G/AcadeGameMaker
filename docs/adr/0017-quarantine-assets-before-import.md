# 외부 에셋은 증적과 함께 격리 보관한 뒤 임포트한다

무료 에셋 확보는 `공식 원출처 확인 → Sol 라이선스 승인 → 원본 아카이브 격리 다운로드 → SHA-256·라이선스 증적 기록 → Luna 독립 검수 → Unity 임포트` 순서로 수행한다. 조사와 격리 보관은 구현이 아니므로 VD-08이 Review인 동안에도 진행할 수 있지만, Unity 프로젝트 임포트와 파생 에셋 제작은 VD-08 Approved 및 OD-ART-001 해결 전에는 금지한다.

에셋을 곧바로 프로젝트에 넣는 방식은 빠르지만 출처 혼입, 라이선스 변경, 파일 변조, 픽셀 밀도 불일치의 원인을 추적하기 어렵다. 원본 아카이브는 Git에서 제외한 로컬 `third_party/quarantine/`에 보존하고, 출처·라이선스·검증일·체크섬 증적은 버전 관리되는 `docs/assets/`에 남긴다.
