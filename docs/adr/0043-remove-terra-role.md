# ADR-0043: 테라 역할 제거와 솔 설계·구현 통합

- 상태: accepted — 2026-10-07 사용자 정정 즉시 반영.
- 범위: 현재 역할, 신규·재시도·대체 작업자 배정과 이름. 제품 행동·허용 파일·필수 검사·승인 권한은 변경하지 않는다.

사용자가 `terra61` 작업자에 대해 테라를 서브에이전트에서 제거한 기준을 상기시켰다. 현재 AGENTS.md와 운영 문서에는 테라 구현 역할이 남아 있었고, 재개 시 실제 `gpt-6.1-sol` 작업자에 `terra61_b1_return_access_resume`라는 이름을 배정했다. 테라 모델을 호출한 것은 아니지만 제거된 역할을 다시 배정한 것이므로 이 작업자를 중단했다. 중단 후 구현 대상 AssemblyInfo.cs의 이전 지문과 새 구현 보고 부재를 확인했다.

이후 활성 역할은 아스트라·솔·루나 셋이다. 솔이 기존 한정 설계와 구현·콘텐츠·구현 검사·시험 자료·검사기·편집기 및 재현 도구를 담당한다. 필요한 경우 서로 다른 솔 작업자에게 과업을 나누되 테라 역할이나 테라 이름의 작업자를 만들거나 재개하지 않는다. 아스트라는 계약 승인과 최종 통합을, 루나는 구현자로부터 분리된 독립 검증을 유지한다.

현재 호출 기준은 아스트라 `gpt-6-astra`, 솔 `gpt-6.1-sol`, 루나 `gpt-6-luna`다. ADR-0041의 같은 계열 상위 안정 숫자 버전 자동 적용은 유지하며 테라 별도 배정 조항만 이 결정으로 대체한다. 현재 도구 목록에 더 높은 안정 버전이 없어 모델 버전 승격은 발생하지 않았다. GPT-5.6 복귀·외부 모델·별도 유료 경로는 허용하지 않는다.

기존 Approved 계약의 테라 담당 배정은 이후 솔 구현 담당에게 인계한다. 행동 요구, REQ/AC, 허용 파일, 검사 계획과 종료 조건을 그대로 적용한다. 담당 이름 변경을 제품 계약의 추가 승인이나 검사 면제로 해석하지 않는다. 과거 ADR-0027·0032·0037·0040·0041과 동결 계약·소스·인계·승인 원문, 역사 작업명 및 실제 모델 참여 증거는 덮어쓰지 않는다. Q0 인간 승인·세대·키·원격 게시 관문과 일일 오전 8시 감사 정책도 유지한다.

보조 모델 확인 자동화는 기존 상태와 일정·대상 대화를 유지하고 현재 역할 안내만 맞춘다. 이 정정으로 일시정지 자동화를 재개하거나 새 예약을 생성하지 않는다. 현재 운영 문서와 위키의 로컬 탐색 보기를 갱신하며 원격 게시 완료를 주장하지 않는다.

후속 사용자 요청으로 같은 날 `게임 작업 모델 기준 자동 갱신` 예약 `automation-2`를 삭제했다. 도구의 삭제 완료를 확인했으며 재생성하지 않는다. 새 작업 배정 직전 실제 가용 모델 확인은 유지하고 일일 오전 8시 진척 감사 예약은 이 요청으로 변경하지 않는다. 위 문단의 일시정지 유지·역할 안내 갱신은 삭제 요청 전 처리 이력이다.
