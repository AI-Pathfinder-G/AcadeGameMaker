# 첫 플레이 가능 버전은 Godot 4.7.2와 GDScript로 제작한다

Windows PC용 2D 데모와 소규모·멀티에이전트 개발을 우선하므로 첫 플레이 가능 버전은 Godot 4.7.2 표준판과 GDScript로 제작한다. Unity는 더 큰 에셋 생태계, C# 도구, 콘솔 및 상용 지원에서 유리하지만, 현재 범위에서는 Godot의 전용 2D 작업 흐름, 텍스트 중심 장면과 스크립트, MIT 라이선스, 가벼운 반복 개발이 더 중요하다. `무게 전이` 프로토타입이 완성되면 물리 제어, 작업 충돌, 성능을 검토하여 엔진 유지 여부를 한 번 재평가한다.
