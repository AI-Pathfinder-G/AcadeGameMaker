# 보스전 공간 확장과 진보스전의 역방향 압축

2026-09-08 사용자 결정. 보스전을 모두 한 화면으로 통일하지 않는다. 초반은 한 화면에서 기본 전투를 익히고, 중반은 복합 기믹과 난이도 상승에 맞춰 공간을 확장하며, 최종 보스전은 거대한 보스가 발사하는 중력 장치를 활용하는 두 단계 이상의 페이즈와 고피해 패턴 학습을 중심으로 한다.

반면 진보스전은 권능과 장치 기믹이 봉인된 뒤 좁은 공간에서 도언이 자신의 능력으로 맞서는 처절한 근거리 결전이다. 마지막을 더 큰 전장으로 만드는 대신 퇴로를 줄여 두 인물의 대립에 집중한다. NPC 공명은 봉인의 원인이며 직접 전투를 대신하지 않는다. 자동 승리, 강제 피격, 보유 기술 삭제, 엔딩 자격 변경은 이 결정에 포함하지 않는다.

오르단은 초반 한 화면형으로 진행해 OD-M5D1-001을 해소한다. 후반 전체 게임 방향을 수직 데모의 구현 범위로 확장하지 않으며, 정확한 전장·보스 형상·장치 동작·피해·실패/재시도 규칙은 별도 Approved 구현 계약에 둔다. 고정 배율·640×360 내부 화면·2560×1440 기준 출력은 유지한다.

## 2026-09-08 후속 정정 — 진보스는 더 어려운 숙련도 결전

사용자는 진보스의 이벤트전 해석을 명시적으로 철회했다. 중력 스킬 편법이 배제된 좁은 공간에서 상대적으로 파괴력이 낮은 연대 기술 경로의 도언이 축적한 레벨·자기 능력·플레이어 숙련과 NPC들이 만든 기회로 더 어려운 진보스를 이겨야 한다. NPC 공명은 싸울 기회를 만들고 도언은 직접 승리한다. 이전 문서 검토의 이벤트전 표현은 이 정정 이전의 이력이며 현재 설계 근거로 사용하지 않는다. 패턴·난이도는 체력 부풀리기나 강제 피격이 아닌 학습 가능한 고난도 공방으로 구체화한다.

## 후속 지시 — 보스 정체성과 반복 제한

사용자는 같은 보스의 반복으로 재미가 줄어드는 것을 피하도록, 두 번 이상 상대하는 보스 캐릭터를 최대 한 개체로 제한하고 나머지는 서로 다른 캐릭터로 채우도록 지시했다. 강력한 생물 보스 한두 개체도 허용했다. 이 반복 상한을 설계 제약으로 수용한다. 라겐만 최종/진보스에 반복하고 오르단 재대결을 새 5장 보스로 교체하는 구체 디자인은 별도 Draft에서 검토한다. 기존 오르단 런타임과 새 캐릭터 승인 범위를 혼동하지 않는다.
