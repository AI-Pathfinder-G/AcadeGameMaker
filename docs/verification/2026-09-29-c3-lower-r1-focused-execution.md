# C3 하위 확인 요청 집중 실행

날짜: 2026-09-29. 구현: 테라. 실행·기록: 아스트라. 보정 후 독립 검수와 통합 수용은 아직 없다.

사용자 원격 병합·후속 작업·재개 지시에 따라 Approved C3의 하위 단위를 구현했다. 루나의 최초 구현 P1 두 건 이후 같은 허용 파일에 보정이 반영됐지만, 테라·솔이 사용량 한도로 중단돼 완료 보고와 최신 정확 지문 독립 검수는 남아 있다. 할당량 오류 후 외부 호출을 반복하거나 별도 유료 경로를 사용하지 않았다.

## 실제 결과

고정 Unity `6000.6.0f1`의 사전 확인을 통과하고 승인된 실행 도구로 편집 모드 집중 검사를 수행했다. 새 하위 10개와 기존 관찰 11개, 총 21개 모두 통과했다. 실패·건너뜀·판정 불가·중복 시험 이름·선택 이름 차이는 각각 0이다. 실행 전후 입력 876개의 경로·SHA-256 차이도 0이다.

실제 시험 시각은 한국 시각 07:14:39부터 07:25:18까지이고 시험 자체 소요 시간은 약 639초다. 실행 도구는 완료·종료 코드 0을 반환했고 실제 소유 Unity PID 30724는 종료됐다. 보조 실행기 종료도 0이었다. 시험 제한·필터·소스는 실행 중 변경하지 않았다.

## 추적과 한계

REQ-M5D7QC3-001/002/004/006/007의 제한된 하위 범위이며 AC-M5D7QC3-001/004/008의 실제 capture 결합, 재관찰, 등록되지 않은 후보 거절과 예약 이후 종료 관련 집중 증거다. AC-M5D7QC3-009의 하위 API 읽기 검토와 선행 입력 대조 기록도 남겼다. 이전 수용 입력 874개와 비교해 하위 런타임 1개 변경·새 시험 및 메타 2개 추가 외의 경로·지문 변경은 없다.

시험 이름에 복제를 언급하는 것만으로 모든 복제·반사 손상 행을 수용하지 않는다. 예약 전 훼손 행, 발급 witness 반사 행과 모든 남은 음성 행의 충분성, 최초 P1 폐쇄는 최신 정확 소스 독립 검수에서 확인해야 한다. 현재 실행은 기존 C3L 집중 회귀를 포함하지만 새 소스의 C3L 전체 필수 회귀 수용을 대신하지 않는다.

실제 Q-B 출처, 상위 소유자, Confirm/Cancel 경쟁, 취소 후 cursor 재무장과 필요한 전체 편집/실행 모드 회귀는 수행하지 않았다. C3 전체 AC-M5D7QC3-010과 ADR-0036 선행 수용은 미완료이며 전체 AC-M5D7QC3-007/008도 Open/Not Verified다. C4는 Review를 유지한다. 다음 순서는 [병합 이후 인계](../handoffs/2026-09-29-merged-c3-lower-checkpoint.md)를 따른다.
