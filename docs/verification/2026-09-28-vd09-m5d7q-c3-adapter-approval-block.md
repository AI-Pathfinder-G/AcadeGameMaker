# 새 게임 확인 처리 — 실행 관리자 변경 승인 대기

날짜: 2026-09-28. 기록: 아스트라.

## 완료한 이전 범위

C2/C2R은 루나의 최종 독립 검수 P0=0/P1=0 후 수용했다. 당시 동결된
소스 기준으로 현재 편집 모드 562+51=613건, 실행 모드 536+74=610건의
정확한 범위별 결과를 확인했다. 별도 실제 프로세스 복구 증거도 수용했다.
이 결과를 이후 변경된 C3/C3L 코드의 실행 결과로 재사용하지 않는다.

## 현재 변경분과 미검증 범위

테라는 승인된 C3L에 따라 다음 두 파일에 관찰 전용 보완을 적용했다.

- `Assets/AcadeGameMaker/Runtime/Profile/ProfileNewGameResetServiceV1.cs`
  지문: `BAE684476B4F38A5E80322FEE6E91034D4BF2952EC51944240965C4C96B67B9D`.
- `Assets/AcadeGameMaker/Runtime/Profile/ProfileResetDiskTransactionV1.cs`
  지문: `13675608C636F1C6B05B10CADB62F4E157FA6300742B37FCDBCA5A6FA949317E`.

구현 추적: REQ-M5D7QC3L-001/002/003 및 REQ-M5D7QC3-002/004.
공백 검사만 통과했고, 빌드·Unity 실행·루나 독립 소스 검수·최종 수용은
아직 하지 않았다. AC-M5D7QC3L-001부터 -005와 C3 구현 기준은 미검증이다.
이 두 파일은 기존에도 미추적 파일이므로 일반 변경 비교의 출력 부재를
변경 없음이나 검증 성공으로 취급하지 않는다.

## 차단 원인과 필요한 좁은 승인

테라의 실행 관리자 단독 변경이 안전 심사에서 거절됐다. 거절 사유는
해당 파일이 변경 승인 지문에 묶여 있으며, 필요한 파일 변경에 대해
신뢰 가능한 사용자 승인 또는 아스트라의 허용 범위·지문 승인이 제시되지
않았다는 것이었다. 기존 C3 승인 계약과 C2/C2R 수용을 확인한 좁은
재제안도 차단됐으므로 추가 반복·우회·심사 설정 변경을 하지 않는다.

대상 파일:
`Assets/AcadeGameMaker/Runtime/Input/Unity/DesktopProfileLaunchAdapterV1.cs`.
필요한 변경은 `GetAuthenticatedLaunchRootForNewGame(InputRouter)`라는
내부 읽기 전용 조회 함수 하나다. 원래 시작한 실행 소유자·입력 관리자·
두 프로필 경로 증거가 정확히 일치하는지 확인한 뒤 기존 경로를 반환한다.
새 경로 조회, 파일 쓰기, 초기화 실행, 입력 활성화, 장면 변경은 하지 않는다.

실행 관리자 현재 지문은 그대로
`0DC2D05B209CB49EA6A44DACA0B76687A30597EE999ACE68AD20C6DF93B51D20`다.
검증용 Q0 지문 파일도 변경하지 않았다. Q0 변경은 향후 루나의 정확한
소스 검수와 아스트라의 별도 지문 승인 후에만 가능하며 이번 사용자
확인 요청에 포함하지 않는다.

사용자에게 위 실행 관리자 함수 추가만 명시적으로 승인할지 요청한다.
답변 전에는 해당 파일을 다시 변경하거나 새 구현·Unity 실행을 시작하지
않는다. 예약 재시도는 만들지 않았으며 현재 동료 작업도 종료됐다.
