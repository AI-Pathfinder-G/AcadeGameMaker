# C3 하위 소비 상태 무결성 보정 구현 기록

2026-09-29 테라 구현 역할의 별도 `gpt-6-sol` 작업자 `/root/terra6_c3_resume`가 [제한 승인](../approvals/2026-09-29-c3-lower-boundary-implementation-approval.md)의 두 파일만 보정했다. 아스트라는 완료 보고의 정확 지문과 집중 선택 목록을 로컬에서 대조했다. 이 기록은 컴파일·실제 시험·독립 수용 결과가 아니다.

실제 witness 키의 별도 비공개 생애 기록에 불변 사건을 보관하고 정수 상태와 함께 검증한다. 원본 발급 연결·세 리프 투영·현재 루트 검사와 외부 문맥의 인증 전 비소모를 유지한다. 정상 중복·경합 패자는 승자의 정상 사건을 종료하지 않는다. 상태 정수만 복원한 경우 불변 사건과 불일치하여 재발급·재예약·재완료를 거부한다. 완료 및 종료 이력은 보존한다.

예외 종료는 `ClosedHistory=Head`, 사전 생성 종료 사건 대입 및 정수 쓰기로 추가 할당 없이 처리한다. 실제 요청·예약 쌍은 등록 전에 사건에 연결한다. 중간 등록 실패 시험은 실제 첫 등록 이후 후속 등록 실패를 유도하고 부분 등록된 쌍과 종료 이력을 확인하도록 작성했다. 제품 장애 주입 API나 정상 권한의 합성 발급기를 추가하지 않았다.

시험 원문은 `[Test]` 18개와 `[TestCase]` 55개로 73행·25개 방법이다. 기존 59행에 단일 필드 복원·등록 실패·경합의 14행을 추가했다. 경합은 주 스레드 정상 승자와 실제 잠금 대기 패자만 확인하며 Unity의 일반 작업 스레드 지원을 주장하지 않는다. 작업자 예외와 종료를 수거한다. 기존 관찰 11행을 포함한 동적 집중 선택은 `artifacts/c3-lower-r2-selection.json`의 84개이며 아직 실행하지 않았다.

추적은 `REQ-M5D7QC3-001/006`, `AC-M5D7QC3-001/004/008/009`의 하위 부분 범위다. 기존 21/21은 다른 지문의 실행 이력이다. 새 상위 소유자·재무장과 필수 회귀, C3 전체 및 C4 수용은 남아 있다. C4 결과·보고·identity 추출·C1/C2 호출 권한은 추가하지 않았다.
