## 계획 v2와 실행 전 경계

계획 v2 지문은 `7690DBC504D04908931C47C7E7CA3FD4FF3D26814085E630703DBF321D319797`이다. 계획 v1과 비교해 원장·입력 목록 참조 및 네 수정 도구의 지문만 바뀌었다. 아홉 실행의 순서, 선택·행 ID, 제한 시간, 명령행 길이, 72개 출력 경로, 잠금은 동일하다. 기존 72개 실행 출력과 큐 결과 파일은 모두 없는 상태다. 이전에 실패한 계획 v1은 보존되어 있다.
