# C3 R11 Edit 분할 계획 및 게시 blob 보완 독립 검토

**정적 P0 0, P1 0.** 91개 matrix 사례와 나머지 149개 Edit 선택은 R11의 원래 240개 이름을 중복·누락 없이 나눈다. 이 판정은 두 선택을 실행할 준비가 됐다는 범위이며 시험 통과나 AC 수용이 아니다.

R11 14파일 동결 manifest는 현재 파일 해시와 모두 일치한다. Edit 원 선택 지문 `66B62A29BC1626A72D60607CA92DA6C880D09870D16CE0D16201DC117CAC4CF6`, 예상 행 원장 지문 `D1B9CBDA4AF477B5C10FC14893F0C58B2BAE676A38E15987C87B7D918658C9C6`, manifest 지문 `0A36C9E7CCF3EBBF477B96C1B742344021D642586AD906042E48C755258571EB`가 계획에 연결된다. 377행의 고유 `ExpectedCase` 91개는 matrix 선택 이름과 정확히 같다. 나머지 선택은 보완집합 149개이며 둘의 합집합은 240개, 중복·누락·초과는 0이다. 모든 선택 이름을 정규식 특수문자 이스케이프 후 `^...$`로 고정하며 각 이름이 정확 한 분할에만 속한다. 각 분할의 `SourceFiles`는 원 선택과 같다.

계획은 QA 도구의 정규화·Windows 인자 인코딩 규칙과 고정 Unity 경로 길이 61을 기준으로 명령행 길이를 기록한다. 독립적으로 같은 인코딩 규칙을 대조·계산한 결과 matrix 14,455자, 나머지 24,170자이며 Windows 한도 32,767자 미만이다. 91/149 개수, 선택 식, 명령 길이에 정적 차단은 없다. generator는 기존 두 selection 또는 계획 파일이 있으면 중단한다. 이 검토 당시 계획 XML/log 목적지는 없었으며 기존 목적지에 대한 QA 도구의 `New-OutputPath` 거부 규칙과 맞았다. 180초 시험 제한, 원래 선택·행 순서, 377행 실대조를 바꾸지 않고 합성 XML을 만들지 않는 계획이다.

게시 blob 보완 `artifacts/c3-r11-documentation-git-blob-equivalence.json` SHA-256 `39D9198AB2939431EC6AAF1FA0F5E282710452E8A147D4B3B964C45BC66DA39C`는 게시 커밋 `a201f94d63a5769ece032c9e442128ca3352cde8`의 137개 파일을 기록한다. 보고된 분류는 로컬 원시 바이트 동일 66개, CRLF에서 LF로만 바뀐 파일 71개, 기타 불일치 0개다. 보조 생성기는 원장 현재 원시 SHA를 먼저 대조한 후 각 경로의 Git blob 바이트가 원본 또는 `CRLF→LF` 변환과 같은지 판정한다. 따라서 기존 로컬 SHA를 바꾸지 않고 줄바꿈 변환과 동일성 주장을 구분한다. 본 검토는 artifact와 코드를 정적으로 읽었고 Git blob을 다시 조회하거나 생성기를 실행하지 않았다.

Edit 분할 선택 계획과 게시 바이트 설명 모두 수용 범위를 확대하지 않는다. Edit 240개 실행, matrix 실제 XML의 377행 검증, 나머지 필수 회귀는 별도 실제 결과와 판정이 필요하다. 본 독립 검토자는 코드·선택·QA·Unity·Git·네트워크를 실행 또는 수정하지 않았다.
