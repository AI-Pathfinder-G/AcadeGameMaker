# 원문 보관 결과의 아스트라 기계 대조

`AC-PLAT-057/058`의 제한 대조. 최종 도구·보관 JSON·시험 JSON·테라 보고의 실물 SHA-256은 각각 `AA71CF71B30A5457AE17E63F37A7ADC5036AB0518BA1D58D0E98F4CFBA6A91FE`, `E3B86595404638BC15F3CB1281057044ACC731B3C6602542ADA6FAF8126BEAEA`, `1DA7BD09702E0E4EA99DE2541A2620DED94459DB617D8E0717B0047817DE3469`, `E0EC727BEBC07855156F3398F5D3B1D8EDDCEDF7FA798C598BB6BA34B6DEB48B`로 소유 보고와 일치한다.

보관25행 Base64를 주 작업자가 실제 복원해 원시 SHA를 재계산했다. 모든 지문·역할 `CurrentRawBaseline`이 일치했고 역사바이트 검증 및 게시 허용 플래그는 거짓이다. 실제 기록은534개·전이25·무변환509이며 원문/후보의 도구 내부 전후 지문이 각각 동일하다. 원본 시험 원장은 보강 전 소스SHA와 최종 소스SHA를 구분하고 두 합성 실행 묶음을 보존한다.

이 대조는 실제 도구를 다시 실행한 결과가 아니며 원문25의 역사 승인 적합·전체 의존 폐쇄·게시 허용도 아니다. 새 루나 소스/실행 기록 검수가 완료돼야 제한 수용을 발급한다.
