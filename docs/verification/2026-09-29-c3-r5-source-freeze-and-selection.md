# C3 r5 소스 동결과 실행 전 선택

후속 실제 실행 기록: r5 첫 집중 실행은 신규 감사 시험 메타 파일의 33자리 식별값 때문에 자산이 무시되어 컴파일 종료 1·XML 부재로 끝났다. 전후 입력 884개의 지문 차이는 0이며 실패는 `artifacts/c3-r5-focused-edit-r1-failure-verification.json`과 원본 로그에 보존했다. [제한 보정 승인](../approvals/2026-09-29-c3-audit-test-meta-guid-correction-approval.md)에 따라 메타 파일의 마지막 한 글자만 제거했다. 새 r6 원장 `84B36B9A4E62BCE98206320EA4D3CBE26CCBCBF590FFA505486CF932E568776B`은 아래 r5와 해당 메타 파일 한 개만 다르다. 코드·377개 내부 행·155/14 선택은 같다. 새 메타 지문 검수와 실제 재실행 결과는 별도로 기록하며 첫 실행을 통과로 바꾸지 않는다.

추적은 REQ-M5D7QC3-001..007과 AC-M5D7QC3-001..006/009/010 및 AC-007/008의 실행 연결 전 부분 범위다. 아스트라는 작업자 완료 통보 후 기존 r4의 14개 경로를 독립 재계산했다. `artifacts/c3-upper-r5-frozen-source-manifest.json` 지문은 `B9DC34D615ECE99775C927FB434D88BB53F0B2F9E356BF8FECB2EB2D4483C9EE`다. 변경은 Q-B 발급 분류, 확인 소유자, 신규 편집·실행 시험 네 파일이며 나머지 열 경로는 동일하다. 실행 관리자·라우터·presenter·하위와 기존 감사의 지문은 변경하지 않았다.

확인 소유자는 일곱 진입점에서 게이트 획득 이후 동일 실제 권한을 재확인한다. 정상 소비·교체·종료된 호출의 거절은 종료 처리 구간 밖에서 수행하고 미소비 원본의 무결성 손상은 안에서 전체 폐쇄한다. 실제 정상 비활성화 후 늦은 요청을 거절하는 회귀도 포함한다. 정확한 인증과 게이트 획득 사이의 지연 경쟁 순서는 실행 재현하지 않았다. 최종 소스 구조와 실제 일반 경합·중복·늦은 권한 시험으로 검증하는 제한 범위다.

아스트라가 집중 선택을 독립 생성해 편집 모드 155개, 실행 모드 14개를 확인했다. 내부 분류·파일 재관찰 예상 행은 377개이고 중복 ID는 0이다. r4와 행의 내용·순서는 같으며 현재 시험 소스 지문과 예상 목록의 지문이 일치한다. 이는 실행 전 선택 확인이며 통과 결과가 아니다. 최종 실행에서 XML의 실제 내부 행 출력과 시험 이름·종료·전후 소스 지문을 대조한다. 필수 562/51/610 회귀 선택은 유지한다.

변경된 런타임·입력 편집 시험·입력 실행 시험의 독립 컴파일은 실제 종료 0이며 최종 편집 시험 보정 후 재컴파일도 종료 0이다. 기존 Bee 참조를 사용하므로 새 Unity 전체 빌드와 시험을 대신하지 않는다. 최초 편집 시험 DLL의 원본 바이트는 별도로 보존되지 않았고 마지막 컴파일이 같은 출력 경로를 덮어썼다. 최초 기록과 최소 최종 기록을 보존한 `input-editmode-final-evidence-supplement.json`은 이 부재 및 최종 명령·응답 파일·소스·로그·출력의 연결과 사후 조회 한계를 명시한다.

같은 취소의 전체 비교는 실제 임시 실행 묶음의 세 파일, 메모리/reset 대상의 존재 여부, 입력 자산·맵·바인딩·활성 상태, 영수증·이력, 장면과 시험 소유 실행 관찰값을 대상으로 한다. 실제 메모리 셀이 없으면 부재를 비교하며 게임 전체 메모리나 실행 세션의 보존으로 확대하지 않는다. 최종 독립 검수와 실제 Unity 실행·단계 수용은 별도로 남아 있다. C3 전체 AC-007/008은 미검증이며 C4는 Review다.
