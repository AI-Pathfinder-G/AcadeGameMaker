## 실제 실패와 종료

실제 53필드 계획의 파일 생성 전 검사에서 `Test-Q0ExecutionSchemaNode` 260행의 `$prefix.Count`가 실패했다. 실제 호출 스택은 해당 함수 260행·250행, `Assert-Q0ExecutionSchema` 295행, 계획 생성 본문 91행이다. 258행의 조건식이 빈 배열을 출력하면 대입 결과가 null이 되는 경계와 일치한다. 이 단계에서 계획 파일은 생성되지 않았다. 검사기를 덮어쓰거나 대체 검사로 실행을 우회하지 않았다.

아스트라의 실패 정리 판정 뒤 큐와 발급자에 각각 정확 중단 요청을 보냈다. 큐는 `AUTHORIZE_REJECTED`와 자연 종료 2, `ExitObserved=true`, `CreatorHandleRetained=true`를 반환했다. 발급자는 `IssuerBoundaryRejected`, `NewSessionInvocationCount=1`과 실제 종료 2를 반환했다. 소유자 39300·큐 49792·발급 외부 소유자 41668이 더 이상 실행 중이지 않음을 확인했다. 프로세스 종료 관측을 물리 메모리 삭제 증명으로 표현하지 않는다.

최종 확인 당시 `execution-plan.json`, `execution-plan.approval.json`, `execution-consumed.json`, `queue-result.json`은 모두 없었다. 서명 요청 0, 실행 승인 0, 실제 아홉 실행 0이다. 공개 권위 게시와 전체 실행 수용을 구별한다.
