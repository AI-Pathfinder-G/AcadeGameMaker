# C3L 관찰 경계 집중 실행 기록

날짜: 2026-09-28. 구현: 테라. 실행·통합: 아스트라. 독립 검증: 루나.

REQ-M5D7QC3L-001..003과 REQ-M5D7QC3-001/002/004/007의 하위 관찰 경계를 구현했다. 사용자 승인 읽기 전용 원래 루트 조회, 실제 관찰 잠금, 실제 시간 초과 발급 증거, 같은 잠금 아래의 세 리프 관찰·해독 투영, 비공개 발급 자료 검증을 포함한다. 기존 저장·초기화 본문은 새 구간을 메모리에서 제외하면 수용된 R36 전체 파일 지문과 정확히 일치한다.

## 실행 이력

R1은 시험 이름 공간 누락으로 컴파일이 실패했고 결과 파일이 없다. R2는 11개 중 10개 통과, 1개 시험 준비 실패다. 실제 실행 준비에서 만든 잠금 파일을 디렉터리 시험으로 바꾸기 전에 삭제하는 처리가 빠졌으며, 런타임은 수정하지 않았다. 두 실패를 보존하며 통과로 소급하지 않는다.

R3은 프로젝트 고정 Unity `6000.6.0f1`과 승인된 실행 도구로 실제 수행했다. 실행 환경 사전 확인을 통과했으며, 도구가 소유한 편집기의 종료 코드 0과 결과 파일을 확인했다. 집중 시험 11개 모두 통과했고 실패·건너뜀·판정보류는 각각 0이다. 예정된 전체 시험 이름과 실제 이름 차이 0, 중복 이름 0, 실행 전후 입력 874개의 경로·SHA-256 차이 0이다.

## 수용 기준과 한계

AC-M5D7QC3L-001은 선행 본문 정확 재구성과 정적 검수로 확인했다. AC-M5D7QC3L-002는 실제 5초 공유 잠금과 조기 해제로 확인했다. AC-M5D7QC3L-003은 실제 루트 파일·잠금 디렉터리·읽기 점유 실패, 상대 경로·파일 시스템 루트 거절, 실제 시간 초과와 위조·오류값 변조 거절을 확인했다. AC-M5D7QC3L-004는 초기화 표식 파일·디렉터리 거절, 리프·투영 변조 거절과 원래 파일 바이트 보존을 확인했다. 재분석 지점 거절은 기존 경로 검사에 대한 정적 근거이며 이번 실행 시험의 통과로 주장하지 않는다.

AC-M5D7QC3L-005는 필수 회귀 실행과 최종 독립 검수 전까지 미검증이다. C3 전체 소유자·취소·새 세대 처리와 AC-M5D7QC3-010은 아직 수용하지 않는다. C4는 검토 상태로 실제 초기화·게임 시작 연결을 구현하지 않는다. 문서 브랜치·위키 게시와 별개로 실제 변경 요청 생성은 인증 갱신을 기다린다.
