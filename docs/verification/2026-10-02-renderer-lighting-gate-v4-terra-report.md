# Renderer2D 실제 재질·조명 대조 v4 테라 보고

승인된 REQ-PLAT-073/074·AC-PLAT-071/072 범위의 격리 Unity 실행을 한 번 수행했다. 실제 프로세스 종료코드는 1이다. 진단 소스의 장면 핸들에서 정수로 암시 변환하는 다섯 위치가 Unity 6000.6.0f1에서 CS0619 컴파일 오류가 되어 executeMethod에 도달하지 못했다. 따라서 재질·셰이더 런타임 식별, 미리보기 조명 등록, 점 조명 켜짐/꺼짐 프레임, 픽셀 차이, falloff 소비는 모두 미관측이다. 로그는 GetRawData 사용을 제안하지만 이 계약에서 소스를 수정하거나 다시 실행하지 않았다.

원문534·후보534·후보505·실행본505와 캐시·설정·기존 진단/루나 증거의 전후 SHA 일치: True. 소스·메타와 로그 SHA, 실제 오류 줄 및 UTC는 JSON에 기록했다. 기존 Renderer GUID7 P1과 전체 의존 폐쇄·게시·전체 수용·루나 독립 수용은 모두 미완료다.
