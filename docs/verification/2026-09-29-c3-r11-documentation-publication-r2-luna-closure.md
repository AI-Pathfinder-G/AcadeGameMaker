# C3 R11 문서·증거 게시 후보 R2 독립 폐쇄 검토

R1 검토에서 지적한 QA 도구 범위와 원격 브랜치 덮어쓰기 방지를 새 지문에서 다시 확인했다. 선택 원장 SHA-256 `F1FCF68057231F2C82C991CBB3285C4026CEA0C10BF244478BDF3E704D8C67FB`의 137개 파일은 전부 존재하며 길이·SHA-256 불일치가 없다. 합계는 문서 91개, 데이터·증거 46개, 4,868,151바이트다. R1 원장과 비교한 차이는 실행 가능한 파일 세 개 제외뿐이며 추가·누락은 없다. 제외한 세 파일은 R2 원장에 로컬 보존 및 이번 게시 범위 밖이라고 명시되어 있다. `.log` 제외 기록도 유지되고 R11 검수·부분 수용 문서는 포함됐다.

게시 스크립트 SHA-256 `1C7CAB9F4F441EF14ED79212DCA8B854AE7A1A80FFD627934FBFC660A1344716`은 원장 지문·137개 고유 경로·허용 경로/확장자(`docs|artifacts`, `md/json/xml`)·각 현재 파일 SHA를 확인한다. 원격 동명 브랜치 조회에서 존재(종료 0)하면 거절하고, 미존재(종료 2)일 때만 진행하며 그 외 반환은 오류로 중단한다. push에는 빈 기대값 `--force-with-lease=refs/heads/<branch>:`가 있어 확인과 push 사이 동명 브랜치 생성 경쟁도 기존 ref 갱신으로 이어지지 않는다. 로컬 브랜치 사전 확인과 임시 index 사용, 마지막 HEAD/index 지문 대조도 포함돼 있다. R1에서 지적한 두 P1은 닫혔다.

위키 초안 SHA-256 `2CF7795EAB066AE35AA4BB4E3884474C7B875F03B78E24D9AA977B370381671B`은 R11 Play 15/15 제한 수용과 관측 한계, 미검증 Edit 240개·377행/91사례·562/51/610 회귀, AC007/008 미수용과 C4 검토 상태, 초기 코드의 승인·근거 공백을 정확히 구분한다. 최종 두 링크를 원격 게시 전 근거로 쓰지 말라는 문구가 남아 있다. 게시가 실제 확인된 뒤에만 이 게시 전 경고를 제거할 수 있다.

**정적 검토 P0 0, P1 0.** 목록은 문서·데이터 범위에 한정되며 초기 게임 코드의 게시나 전체 C3/C4 수용을 주장하지 않는다. R11 실행 결과는 원장과 대조된 제한 Play 증거로만 사용한다. 이번 검토에서는 스크립트, Git, 네트워크, Unity를 실행하지 않았으므로 실제 서버 branch 상태나 게시 성공은 확인하지 않았다. 제공된 원본 HEAD/index 이력은 그대로 참고했으며 새로 독립 조회하지 않았다. 검토문은 동결된 137개 목록에 추가하지 않았다.
