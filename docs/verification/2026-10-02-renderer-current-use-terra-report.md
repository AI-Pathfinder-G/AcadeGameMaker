# Renderer2D 현재 사용 경로 테라 보고

승인 계약 REQ-PLAT-065..067 / AC-PLAT-063..065의 격리 진단을 Unity 6000.6.0f1로 한 번 실행했다. APV 여섯 자원은 로드와 설치 패키지 메타 GUID가 일치했다(AC-PLAT-063 부분 관측). 현재 UniversalRP의 기본 Renderer2DData는 관측했으나, 편집 모드에서 임시 장면 생성이 거부돼 실제 조명 렌더와 falloff는 관측하지 못했다(AC-PLAT-064 실패). 원문534·후보534·후보505·실행본505 및 보호 패키지/설정 지문은 전후 동일하다(AC-PLAT-065 보존 확인). 종료코드 0은 진단 성공을 뜻하지 않는다. 오류 뒤 소스 수정이나 Unity 재실행은 하지 않았다.

기존 Renderer7 P1, 게시, 전체 수용, 의존 폐쇄와 루나 독립 검수는 모두 미완료다. 정확한 원시 관측, UTC, 종료코드, 로그 및 새 소스·메타 SHA는 JSON에 보존했다.
