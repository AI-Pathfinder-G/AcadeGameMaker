# 필수 입력 선별 기계 대조

[Approved 계약](../specs/work-contracts/2026-10-02-code-first-input-selection.md)의 `REQ-PLAT-048..050` / `AC-PLAT-046..048`에 따라 테라 선별 원장 SHA-256 `DB2D4098FECCA9DCD7C4539E7D10145DA286DE44A0FE4A1E46FC599110C458B3`를 대조했다. 523행은 고유 경로523개이며 현재 파일 SHA 불일치0, 행별 다섯 수용 플래그 위반0이다. 참조 변37개의 출처·대상 SHA와 출처 줄의 원문 조각 불일치도0이다. 이는 루나 독립 검수를 대신하지 않는다.

선별후보29개는 검사·선택 입력13개와 시험이 읽는 문서 입력16개다. 488개는 보류, 6개는 기존 원장의 새 바이트 결속이 미입증이다. 29개의 정확 경로는 원장의 `SelectionStatus=선별후보` 행만을 사용한다. 코드79개·조립 정의25개·미디어40개는 현재 필수 검사 직접 근거가 없어 보류했으며 제품에서 영구 불필요하다고 판단하지 않았다.

후보29개를 읽기 전용 Git 객체로 대조하면7개가 CRLF→LF 경계에 있다. 역사 입력의 원본 SHA를 새 SHA로 바꾸지 않고 새 복사본에서 두 지문을 모두 기록해야 한다. 기존 시험 원장·선택의 지문 충돌, 후보 밖 의존6경로, 원격 내용 차이3개 및 Renderer2D P1은 남아 있다. 새534개 검토 후보 작성은 별도 계약이며 실행·게시·전체 폐쇄를 허용하지 않는다.
