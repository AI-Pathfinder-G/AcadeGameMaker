# GPT-6 역할 전환·C3 발급 입력 독립 문서 검수

- 검수자·실제 모델: Luna, `gpt-6-luna`
- 날짜: 2026-09-29
- 범위: 사용자 지시, AGENTS.md, 운영 모델, ADR-0037/0032 및 색인, 위키 발행본, Approved C3와 구현 승인 대조. 코드·설계는 수정하지 않음.

## 판정

P0=0, P1=1.

모델 전환의 규범은 일치한다. 5.6 새 호출·재시도 금지, 기존 5.6 작업자 재개 금지, 과거 참여 사실 보존이 AGENTS.md·운영 모델·ADR-0037에 명시되어 있다. 현재 사용할 수 있는 `gpt-6-sol`·`gpt-6-luna`와 미노출 `gpt-6-terra`를 구분하며, 테라 구현 역할을 별도 `gpt-6-sol` 작업자로 배정한다. ADR-0032의 5.6 표는 과거 배정 이력으로 남아 있고 문서 머리말이 현재 배정에서 대체됐음을 분명히 한다. ADR 색인은 0037을 현재 결정으로 안내한다.

Approved C3의 `AcceptNewGame` 입력은 실제 `IssuedNewGameRequestV1` 참조로 구체화됐고, 구현 승인은 값만으로 pending handle을 찾는 경로를 금지한다. 이전 독립 설계 폐쇄 기록의 고정 제안 지문과 승인 문서의 두 설계 지문이 일치하며, 승인 범위는 기존 REQ/AC·허용 파일 안이다. C4 보고·identity 추출·C1 Begin·C2·실제 UI/장면·새 assembly/friend/public ABI는 계속 제외한다.

## P1 — 위키의 세 작업자 응답 완료 문구가 현재 도구 상태를 앞섬

`wiki/Development-Model.md`는 “실제 구현·설계·독립 검수 작업자를 새로 생성했고 응답을 확인했다”고 적는다. 이번 도구 agent 목록 확인 시 Sol 작업은 완료였지만 Terra 구현 작업은 아직 실행 중이었다. 따라서 해당 문장은 이 검수 시점에 세 역할의 응답 완료를 입증하지 못한다. Terra의 실제 응답 후 사실에 맞게 확인 완료를 기록하거나, 현재는 작업 진행 중으로 표현해야 한다. 이 문구는 승인·코드 범위를 바꾸지 않지만 참여 증거가 최신이어야 한다.

도구의 가시 상태는 Luna 검수 응답과 Sol 완료, Terra 진행 중을 보여 준다. 모델 배정 규칙상 Terra는 별도 `gpt-6-sol` 작업자이며 `gpt-6-terra` 호출로 기록하지 않는다. 세 역할의 응답이 모두 끝났다고 현재 증거만으로 보고하지 않는다.

## 후속 상태 확인 — Terra 두 번째 응답 완료

이전 P1은 당시 도구 스냅샷에서 Terra 작업이 실행 중이었으므로 세 작업자 응답 완료를 확인할 수 없다고 기록한 시점 판정이다. 이후 도구 목록에서 Terra 작업이 `completed`로 바뀌었고, 최초 읽기 전용 응답과 이번 두 번째 보정 완료 응답이 각각 확인됐다. 따라서 위키의 작업자 응답 확인 문구는 참여 응답 사실과 양립하며 P1은 현재 폐쇄한다. 이전 기록의 당시 스냅샷은 지우거나 고쳐 쓰지 않는다. 두 번째 응답은 구현 완료 보고이며, 아직 Unity 실행이나 독립 코드 수용을 뜻하지 않는다.
