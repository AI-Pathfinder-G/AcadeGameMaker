# 표준 문서 정리와 위키 게시 실행 기록

날짜: 2026-09-28. 수행: 아스트라. 독립 문서 검수: 루나.

2026-09-29 보완: 사용자 승인 조회 함수와 C3L 관찰 경계를 구현했고 [집중 실행](./2026-09-28-vd09-m5d7q-c3l-focused-execution.md) 11/11 및 [독립 검수](./2026-09-28-vd09-m5d7q-c3l-r3-luna-review.md)를 완료했다. 필수 편집 모드 회귀 562개는 아직 실행 중이며 별도 프로세스 51개와 C3L 최종 수용은 남아 있다. [ADR-0036](../adr/0036-staged-confirmation-and-execution-acceptance.md)의 검증 순서 보정은 승인했지만 C3 전체는 미검증이고 C4는 Review다. 아래 초기 미검증·게시 개정 기록은 당시 이력이다. 변경 요청 생성의 인증 차단은 아직 해소되지 않았다.

사용자는 이전 세션의 표준 문서를 읽고 정리 내용을 변경 요청과 위키에 게시한 뒤 후속 구현을 진행하도록 지시했다. 별도 사용자 답변으로 실행 관리자 내부 읽기 전용 조회 함수 추가도 승인했다.

## 게시 경계와 실제 결과

로컬 `main`의 작업물·스테이징은 보존했다. 원격 `main`의 `1df1bcd872c445777fc8aa385ba94a8efb32d062`를 부모로 별도 문서 인덱스를 구성해 `AGENTS.md`, `CONTEXT.md`, `docs/`, `wiki/`만 담았다. 문서 브랜치 `codex/documentation-checkpoint-20260928`의 최초 개정은 `4d3fd80079392368f9726e232467f7dd20b36f2a`이며 원격 게시에 성공했다. 누적 문서 변경 577개이며 게임 코드·설정·미디어·실제 검사 출력은 포함하지 않는다.

위키 별도 저장소의 기존 페이지를 보존하고 독자 페이지 14개와 탐색 파일 1개를 게시했다. 본문 개정 `8ea7ee9332779992ae3bf6b5f02d89cd260c7f61`, 게시 기록·권위 링크 정정 개정 `c9e697f1bc1bdb6e69a21450c54471df908b987a` 모두 원격 게시에 성공했다. 실제 GitHub의 `Implementation-Status` 페이지에서 상태 표·후속 경계·문서 브랜치 링크를 확인했다. 위키 내부 연결 누락은 0개다.

GitHub 앱의 변경 요청 생성은 403 권한 오류로 실패했다. 로컬 GitHub 명령 도구의 기존 로그인도 만료 상태다. 저장된 Git 자격 증명을 다른 도구 인증에 사용하는 제안은 안전 심사에서 승인되지 않은 자격 증명 접근으로 거절됐으며 실행하지 않았다. 반복·우회 없이 사용자에게 인증 갱신 또는 비교 화면에서 초안 생성을 요청했다. **실제 변경 요청은 아직 생성되지 않았다.** 이 문서나 위키 게시를 변경 요청 생성 완료로 해석하지 않는다.

## 확인과 한계

인계 핵심 파일 24개의 초기 SHA-256 대조는 차이 0이었다. 이후 사용자 승인 조회 함수는 별도 후속 구현이며 그 결과를 초기 대조 기록에 소급하지 않는다. 기존 마크다운의 줄바꿈 공백·파일 끝 공백을 유지하고 다른 공백 오류를 확인했다. 루나의 상대 문서 연결 검사에서 실제 누락은 없었으며 최신/과거 상태의 충돌과 문서 탐색 누락을 보완했다. 일반 로컬 경로와 당시 프로세스 번호는 비밀정보가 아니며 과거 증거 지문을 보존하기 위해 수정하지 않았다.

AC-M5D7QC3-010과 AC-M5D7QC3L-005는 계속 미검증이다. 과거 C1/C2/C2R 수용 결과와 현재 C3/C3L 변경분을 구분했다. C4는 Review이며 구현하지 않는다. 문서 게시와 환경 사전 확인은 새 Unity 실행·게임 수용 결과가 아니다.
