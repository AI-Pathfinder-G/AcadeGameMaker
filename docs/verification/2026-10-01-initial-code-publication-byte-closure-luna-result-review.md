## 독립 대조

- 후보 원장 경로 489개와 새 원장의 `InitialCandidate489` 경로 집합은 일치했다. 신규 12개는 `C4AdditionalCandidate12`로 분리됐다. 각 501개 경로가 존재하며 `CurrentSha256` 대 실제 파일 SHA-256 불일치 0건이다. C4 신규 12개도 v19 동결 원장의 해당 경로·지문과 일치한다.
- 상태 집계는 현재 직접 입증 60, 정확 변경 승인 필요 24, 문서 출처만 확인 159, 출처 미입증 258이다. 501개 전체의 `PublicationApproved=false`이며 현재 게시 결정도 모두 제외로 남는다. 정확 변경 승인 필요에는 후보 기존 변경 12개(그중 C4 10, 다른 C3 산출물 2)와 C4 신규 12개가 포함된다. 초기 직접 근거 61개를 현행 직접 입증 61개로 잘못 승격하지 않았다. R2의 61행 중 한 경로는 제한 정적 검수뿐이며, 이에 맞춰 현재 직접 바이트 일치는 60개다.

## 한계

이 검토는 원장·실물 파일·지정 문서 줄·보존된 원격 트리의 읽기 전용 대조다. 현재 원격을 다시 조회하지 않았고, 428개 공백을 승인으로 전환하지 않았으며, Renderer2D 출처와 패키지/설정/GUID의 실제 Unity import·compile도 확인하지 않았다. `PublicationApproved=false`, `WholeAccepted=false`와 게시 제외 상태를 유지한다. v15 전체 실행은 진행 중이며 그 결과를 이 원장의 승인 근거로 사용하지 않는다. 코드 게시, Git/원격 변경, Unity·클린 복제 실행은 없었다. 이 새 검토문이 v19 입력 목록 밖임을 쓰기 전에 확인했으며 기존 입력과 실행 증거는 변경하지 않았다.
