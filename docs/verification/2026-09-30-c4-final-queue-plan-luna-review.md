## 실패 정지와 남은 한계

큐는 프로젝트 경로에서 파생된 배타 mutex를 먼저 획득하고, 잠금 버림이나 기존 실행을 실패로 처리한다. 실행마다 계획·원장·도구·선택 지문 및 입력을 다시 확인하고, 기존 출력이 하나라도 있으면 중단한다. 각 실행의 네이티브 프로세스 종료, QA 반환 및 검증을 확인하며 실패 시 다음 실행으로 넘어가지 않는다. 최종 큐 결과 기록은 mutex 해제보다 먼저 수행된다. 계획은 전체 수용을 표시하지 않는다.

이번 검토는 계획 구조·지문·이름 집합·경로 및 인자 길이만 확인했다. 실제 Unity 실행, XML 결과, native 종료 증거, 188개 행의 실행 검증, 9회 사이 입력 동일성은 아직 입증되지 않았다.
