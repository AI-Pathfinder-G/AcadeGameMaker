# Art Direction Canon

## 방향

고해상도 픽셀 아트에 URP 2D 조명, 파티클, 다층 패럴랙스를 결합한다. 도시는 황동 계량기, 배관, 거대한 추, 붉은 체납 도장, 청회색 콘크리트가 반복되는 관료주의 디젤펑크 산업도시다.

환경의 기본 모듈은 18픽셀 정사각 격자를 사용하고 640×360 내부 픽셀 캔버스를 정수 확대해 16:9 2560×1440 최종 화면을 구성한다. 1440p 기준 확대 배율은 4배다.

창과 모니터의 종횡비가 달라도 세계는 같은 16:9 구도를 유지한다. 더 넓은 세계를 노출하거나 화면을 자르지 않고 중앙 gameplay frame 밖을 시각적 여백으로 처리한다.

일반 플레이 카메라는 고정 배율로 주인공의 이동을 예측해 따라간다. 마우스가 화면을 끌지 않으며 상승·낙하와 이동 방향에 따라 앞으로 볼 공간을 조정하고, 장면이 의도한 방 경계를 벗어나지 않는다.

UI는 픽셀 프레임과 아이콘의 정수 확대를 유지하되 글자는 최종 출력 해상도의 SDF로 선명하게 표현한다. 장식의 픽셀 정체성 때문에 정보 가독성을 희생하지 않는다.

색은 21개의 세계색과 11개의 의미 강조색으로 역할을 나눈다. 세계는 냉청회색·먹색을 주조로 황동·녹·콘크리트를 보조하고, 의미색은 조준·전이·선택·핵심 인물을 읽는 데만 사용한다. 히로인의 따뜻한 상아·장밋빛·금색은 보상이나 일반 상호작용 표시로 재사용하지 않는다.

기준 세계색은 `#090D12 #101820 #17232C #20323C #2C424B #3B555D #526B70 #6C8081 #899693 #A9B0A7 #CAC9B8 #211916 #37241E #503027 #704031 #92563A #7B6035 #A47E43 #203D39 #3B6258 #394035`다. 의미색은 전이 가능 `#20E0D0`, 전이 활성 `#F7FFFC`, 쿨다운 `#FFAA2B`, 차단 `#FF3B45`, 수탈 `#C92350 #632E83`, 연대 `#91F3E3 #E7E7C5`, 히로인 `#F0D7B2 #C9858D #D7AE68`이다.

## 통합 원칙

- 서로 다른 무료 에셋은 제한된 공통 팔레트, 픽셀 밀도, 윤곽선, 조명 규칙으로 통합한다.
- 시각 요소는 중력의 계량과 부채, 낡은 기반 시설, 노동 계급을 설명하는 데 우선 사용한다.
- 에셋의 출처, 원저작자, 라이선스, 허용 용도, 수정 여부를 도입 전에 기록한다.
- 에셋 수가 많다는 이유만으로 캐논이나 핵심 플레이 가독성을 바꾸지 않는다.
