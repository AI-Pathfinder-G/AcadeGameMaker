# Game Design Canon

## 제품 약속

정교하게 설계된 횡스크롤 세계와 반복 가능한 조립형 원정을 결합한다. 플레이어는 인간 대리추인 주인공으로서 `무게 전이`를 사용해 이동, 전투, 퍼즐의 결과를 같은 규칙으로 바꾼다.

## 디자인 기둥

1. **하나의 동사, 여러 문제:** 무게 전이는 이동·전투·환경 상호작용을 관통한다.
2. **정밀함을 보존한 반복성:** 검증한 수작업 방의 지형과 점프 품질을 보존하면서 연결, 위험, 보상, 사건을 변주한다.
3. **선택도 플레이가 된다:** 인간성 선택은 강함을 포기하는 선택이 아니라 수탈과 연대라는 서로 다른 기술군을 연다.
4. **세계와 규칙의 일치:** 중력 배급망, 하방권, 중력 부채가 레벨·전투·계층 갈등에서 같은 원리로 드러난다.
5. **공간을 직접 가리킨다:** 왼손 이동과 오른손 포인터 조준을 분리해 적·상자·중력 payload를 화면 공간에서 직접 선택한다.

## 첫 검증 목표

첫 결과물은 약 15분 수직 데모다. 작은 거점 1개, 수작업 방 풀 6개를 이용하는 원정 1개, 이동·점프·대시·벽차기, 상자와 적 대상의 무게 전이, 일반 적 2종, 중간보스 1종, 실패와 부분 초기화, 인간성 선택 1회, 선택별 기술 각 1개, 마지막 히로인 등장 장면을 포함한다.

수직 데모의 한 런은 방 풀 6개 중 저작된 네 방을 사용한다. 시작 `R01`과 수렴 `R06`은 고정되고 가운데 두 방과 소켓 변주는 네 개의 검증 시드로 바뀐다. 선택 직후에는 같은 봉쇄선을 수탈 기술 `압착 판결` 또는 연대 기술 `공동 기준면`으로 돌파해 두 기술이 모두 실제 진행 수단임을 확인한다.

## 명시적 비범위

- 전체 챕터와 완성형 핵심 세계
- 진보스와 `각자의 아래`의 실제 전투 구현
- 완성형 지속 성장과 장기 밸런스
- 후반 무게 전이의 중력 방향 조작
- 출시, 콘솔 대응, 상용 운영
