# AcadeGameMaker

중력이 계량·과금되는 관료주의 디젤펑크 도시를 배경으로, 정교한 횡스크롤 액션과 조립형 로그라이트 원정을 결합하는 2D 게임 프로젝트다. 현재 단계의 목표는 Unity 6.3 LTS로 약 15분짜리 수직 데모를 만드는 것이며, 구현에 앞서 문서와 검증 가능한 사양을 확정한다.
