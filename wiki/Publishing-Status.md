- Local content status: Ready for repository registration

## Remote publication blocker

현재 작업공간은 Git 저장소가 아니고, 확인된 GitHub 인증도 만료되어 있어 원격 Wiki에 안전하게 게시할 수 없다. 원격 저장소와 유효한 인증이 제공되기 전까지 로컬 위키 패키지를 권위 문서와 함께 보존한다.

## Publication gate

1. 원격 저장소 소유자와 이름을 확인한다.
2. Wiki 기능과 권한을 확인한다.
3. `wiki/`의 내부 원본 링크를 실제 저장소의 고정 브랜치 URL로 변환한다.
4. 게시 후 Home, Sidebar, 모든 권위 문서 링크를 클릭 검수한다.
5. 게시 revision과 검수일을 이 페이지에 기록한다.

원격 게시 전에는 `Published`라고 표기하지 않는다.
