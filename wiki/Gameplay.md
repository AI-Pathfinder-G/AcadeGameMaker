# Gameplay

## Core verb

플레이어는 자신의 무게를 상자와 적에게 넘기고 되찾는다. 주인공은 가벼워져 공중 기동이 달라지고, 대상은 무거워져 낙하·충돌·환경 반응이 달라진다. 수직 데모에서는 중력 방향 변경을 다루지 않는다.

## Movement baseline

기준 이동은 최대 속도 8.0, 3.25유닛·28틱 점프, 5유닛·15틱 대시와 벽차기를 사용한다. 가변 점프와 코요테·입력 버퍼는 정밀 조작을 보조한다. 공중 대시는 착지 전 한 번이며 무적을 주지 않는다. 무게 전이 중 점프는 약 5유닛으로 커지지만 모든 필수 길은 기본 이동만으로 통과할 수 있어야 한다.

## Control grammar

왼손은 WASD·Space·Shift로 이동과 플랫폼 조작을, 오른손은 마우스로 공간 조준·공격·무게 전이를 맡는다. 기본 공격은 좌클릭, 전이·회수는 우클릭이며 JKL 전투와 클릭 이동은 사용하지 않는다. 게임패드는 왼쪽 스틱 이동·오른쪽 스틱 조준과 trigger/bumper 전투로 같은 의미 결과를 제공한다.

마우스는 대상 조준 형상 또는 기준 24픽셀 안을 직접 가리키며, 게임패드는 오른쪽 스틱 방향 18도 안에서 대상을 잡고 현재 대상은 26도까지 유지한다. 새 대상이 4도 이상 정확할 때만 바뀐다. 두 방식 모두 플레이어에서 6유닛·LOS 안의 단일 대상만 선택하며 활성 전이는 조준과 무관하게 같은 버튼으로 회수한다.

게임플레이의 마우스 포인터는 총구의 조준점으로 표시된다. 유효 대상을 포착하면 조준점이 커지고 대상 외곽선이 형광으로 강조되어 포착 여부를 즉시 알 수 있다. 메뉴에서는 게임플레이 조준점과 대상 강조를 숨기고 일반 UI 커서를 사용한다. 게임패드 메뉴 조작은 가상 마우스 대신 포커스 이동을 사용한다.

## Expedition structure

지형을 임의 생성하지 않는다. 전체 방 풀은 입출구와 핵심 동선을 검증한 수작업 방 정확히 6개로 구성하고 한 원정에는 4개를 사용한다. 시작 `R01`과 수렴 `R06`은 고정하며 가운데 두 방과 소켓 변주는 지원 시드 101, 202, 303, 404의 검증 snapshot으로 결정한다.

## Progression choice

수탈은 활성 전이 대상에 피해와 경직을 주는 `압착 판결`, 연대는 플레이어만 밟는 임시 발판을 만드는 `공동 기준면`을 제공한다. 두 기술은 같은 봉쇄선을 통과할 수 있지만 타인의 주체성을 다루는 방식이 다르다.
