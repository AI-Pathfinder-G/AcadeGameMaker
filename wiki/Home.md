# AcadeGameMaker Wiki

## 2026-09-28 정리 기준

[[현재 구현 상태|Implementation-Status]]에서 최신 수용 범위와 후속 작업을 확인한다. C1은 저장 초기화, C2/C2R은 메모리·입력 전환과 실제 재시작 복구까지 당시 소스로 검증됐다. C3/C3L은 승인됐으나 구현·검증이 남아 있으며 C4는 검토 중이다. 아래 소개와 과거 준비도 기록을 전체 게임 완성이나 실제 메뉴·장면 연결 완료로 해석하지 않는다.

AcadeGameMaker는 중력을 계량·과금하는 관료주의 디젤펑크 도시에서 인간 대리추가 `무게 전이`로 이동·전투·환경을 바꾸는 2D 횡스크롤 로그라이트 게임이다.

현재 목표는 Unity 6.3 LTS 기반 약 15분 수직 데모의 구현과 검증이다. Unity bootstrap과 결정론적 이동 코어·어댑터를 완료했고, 무게 전이의 순수 M1 계약·선택기·세션도 독립 검증을 통과했다. 무료 에셋 원본은 증적·체크섬과 함께 격리하며 승인된 작업 계약 안에서만 임포트한다.

전체 게임의 서사는 가칭 도언·세령·라겐·아인을 중심으로 한 8챕터 기승전결로 확정했다. 시놉시스는 캐논에 반영됐고, 전체 서사 구현 스펙은 `Review` 상태다.
